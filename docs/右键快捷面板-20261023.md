# Yuki 右键快捷面板

右键雪即可切换「对话 / 剪贴板 / 时间 / 待办」。沿用工作台冷色三主题与原生菜单。

对话支持滚轮查看完整长回复和本次运行最近 60 条记录；向上阅读时不会被流式回复拉到底部。仍使用工作台所选模型。重启不保留这份临时阅读记录。

剪贴板显示最近十条文字记录的简短预览，选中后复制或双击复制原始全文，可暂停记录。时间页直接操作现有专注/休息计时。待办显示五项优先到期的未完成事项，可完成、添加并选择半小时或一小时后提醒；完整列表与设置仍在工作台。

使用根目录 start.bat 启动 Electron 入口。已运行的旧进程需要从菜单保存退出，再启动才能加载新版原生面板；本次未强制关闭用户进程。

验证：前端构建、Node 自动测试、Qt 菜单与中文输入/气泡测试；独立测试用户目录下，实际 Electron + Python IPC 已验证待办新增/完成、专注开始/暂停和快照同步。三主题四页截图在 output/right-menu-20261023。截图包含示例数据，不是用户实际记录。

现有完整工作台 smoke 中旧布局编辑选择器仍有一项失败，本次相关 IPC 验证使用独立的 YUKI_QUICK_TOOLS_SMOKE 分支通过，不将其表述为完整工作台 smoke 全通过。
