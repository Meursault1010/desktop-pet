# Yuki：睡眠与桌面助手升级

更新日期：2026-10-20。

## 打开新版

在项目根目录双击 `start.bat` 或 `start-electron.bat`。Electron 启动入口现在优先选择本次通过验收的版本：

`releases/electron/yuki-win32-x64-idle-states/yuki-win32-x64/yuki.exe`

后续已加入睡觉、站立、坐下、趴着四类待机和动作库分类，详见 [四类待机与动作库说明](四类待机与动作库说明.md)。下文保留睡眠与桌面助手功能的说明及其当时的验证记录。

本次继续使用 Electron 控制台与现有 PySide6 桌宠渲染后端。

## 睡眠

- 按电脑本地时间，在每天 **00:00–07:00** 和 **13:00–14:00** 自动进入持续睡眠。
- 使用已选中的②朝右睡姿和无花纹枕头。呼吸只轻微带动胸口，减少头发、耳朵与枕头的抖动。
- 头顶是无边框的圆润字体 `zzz`，缓慢飘动、淡入淡出。
- 熟睡时暂停自主巡逻、音乐动作、自言自语和桌面事件庆祝。
- 点击、拖拽、主动发消息或较大的系统播放声音可以唤醒；普通鼠标经过不唤醒。声音唤醒需开启“随声音互动”，它读取电脑播放音频，不是麦克风。
- 睡眠时段内被唤醒后，安静 **2 分钟** 再次入睡；拖拽、对话等持续交互会推迟重新入睡。
- 正在拖拽、飞行、附着、手动播放动作或暂停行为时，不强行切换睡姿。

入睡与唤醒预览已获用户认可，现已接入正式动画：入睡约 **1.6 秒**，从半睁眼缓慢闭眼、轻轻落头，再进入持续呼吸；唤醒约 **1 秒**，逐渐睁眼并轻轻抬头。两段素材按 60 fps 生成，实际播放帧率由现有渲染循环和电脑负载决定。

为避免生成图之间头发、枕头和服饰细节跳变，动画复用已选睡姿母版，只融合已认可预览中的眼部变化，并对头部做克制的局部变形。枕头固定；入睡末帧精确衔接呼吸母版，唤醒保留当时正在显示的呼吸画面。入睡过程中被打断会从当前姿势反向抬头；连续点击不会重新播放唤醒。拖拽越过起拖阈值即交给拖拽和抛掷逻辑，不等待唤醒播完。

当前过渡表达的是**卧姿中的闭眼落头和睁眼抬头**；站姿与卧姿之间仍沿用现有姿态切换，并非完整的站立、躺下、起身骨骼动画。

实际 Qt 渲染预览：[入睡、呼吸与唤醒](验收资料/sleep-transitions-20261020/sleep-wake-playback.gif)。素材构建脚本为 `console-v2/build_sleep_transitions.py`，不需要再次上传参考图。

## 模型连接

在工作台进入 **AI 助手 → 模型服务设置**，填写服务地址、模型名称和可选 API 密钥，保存后连接。

- 支持 LM Studio、Ollama 的 OpenAI 兼容 `/v1` 接口，以及兼容 OpenAI Chat Completions 的 HTTPS 云服务。
- 本机默认地址为 `http://127.0.0.1:1235/v1`，本地发现保留 1234 端口回退。请以自己实际启动的服务地址为准。
- 模型名称可以填写服务实际返回的 ID，或留空后从模型列表选择。
- 支持流式回复、多轮对话、停止生成及桌宠气泡显示。当前是文本聊天，没有自动执行模型返回的系统命令。
- 密钥通过 Electron `safeStorage` 加密保存；系统加密不可用时，仅在本次运行保留。更换服务地址不会自动携带旧密钥。
- 使用云服务时，对话会发给填写的服务提供方。剪切板历史不会自动加入提示词或发给模型。

本次真实对话验收连接了本机 `1235` 端口，服务返回模型 ID `qwen3.8-4b-distill`。这是本机模型服务的标识，不代表核实了该名称对应的公开官方发行版本。云端请求格式和认证由自动化测试覆盖，未使用付费云密钥进行真实扣费测试。

## 桌面工具

工作台新增“桌面工具”，沿用蓝、白、银和星辰元素，提供明暗主题、小窗口适配和减少动态效果选项。

### 时钟与天气

显示电脑本地时间、日期与秒数；城市天气包含当前温度、体感、湿度、风速和当日高低温。输入城市名称、拼音或英文查询。天气使用 Open-Meteo，无需定位权限或 API 密钥；联网查询会把城市名发给天气服务。页面打开时定期刷新，短时间重复查询使用缓存。

### 播放器状态

通过 Windows 系统媒体会话读取曲目、艺人、播放/暂停状态和播放器提供的时间进度。播放器必须支持 GSMTC；没有向系统发布状态的应用不会出现在这里。此次实际读取到了本机哔哩哔哩播放器会话。这里只显示状态，未新增播放控制按钮。

### 最近 10 条剪切板

- 从 Yuki 启动后的新复制内容开始记录，最多保留 **10 条不同文本**，按最近捕获顺序排列。
- 点击记录可重新复制；提供暂停记录与清空按钮。
- 只支持文本，单条最多 256,000 字节，不记录图片或文件对象。
- 历史仅在当前进程内存中保留，退出即清除；暂停设置会保存。不自动读取启动前已有的剪切板内容。

### 桌面事件与情绪动作

| 事件 | 检测方法 | 表现与范围 |
| --- | --- | --- |
| U 盘插入 | 约每 12 秒检查 Windows 可移动逻辑盘 | 新盘符出现后记录并庆祝；开机已插入的盘不重复提醒 |
| 接通电源 | Electron 电源事件 | 接入交流电时庆祝；不是逐一读取设备充电协议 |
| 下载目录文件就绪 | 检查系统默认下载目录，大小与修改时间稳定至少 4.5 秒 | 记录并庆祝，排除常见临时下载扩展名 |
| 任务/编译成功 | 显式通知脚本或命令退出码 | 庆祝动作 |
| 任务失败或启动报错 | 显式通知脚本或非零退出码 | 难过动作 |

动作复用现有 `celebrate` / `sad` 素材，没有为每种事件生成一套独立新表情。事件保留最近 20 条，页面展示最近 6 条；动作有 12 秒冷却。睡眠、拖拽、飞行、附着、已有动作播放或安静模式等情况下会抑制反应。

下载检测属于目录稳定性推断，不能覆盖所有浏览器、自定义下载目录、暂停下载或外部下载器；也不会监听所有软件内部错误。需要可靠通知时，请使用下面的显式集成。

## 将编译和其他任务结果交给 Yuki

需要在电脑上安装 Node.js，保持 Yuki 正在运行。通知脚本为项目根目录的 `scripts/yuki-task.cjs`。

在目标工程目录运行，脚本后跟实际编译命令。例如，本项目的前端工程在 `console-v2/frontend`：

```powershell
cd console-v2/frontend
node ../../scripts/yuki-task.cjs -- npm run build
```

脚本保留子命令退出码，并按成功或失败向 Yuki 通知。也可以在现有自动化流程中直接调用：

```powershell
node scripts/yuki-task.cjs --notify success "编译成功"
node scripts/yuki-task.cjs --notify failure "测试失败，请检查日志"
node scripts/yuki-task.cjs --notify download "下载完成"
```

自定义配置目录时，可通过 `YUKI_EVENT_DIR` 指向“桌面工具 → 让雪知道编译结果”显示的任务投递目录，或让脚本使用与应用相同的 `YUKI_USER_DATA`。没有设置时使用默认用户数据目录。Yuki 不会执行通知内容中的命令。
