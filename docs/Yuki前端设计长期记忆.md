## 2. 长期视觉方向

Yuki（雪）的工作台是一间安静、精密、有生命的桌面工作室。整体蓝、白、银，冰冷、深沉、低调的未来感；亲近与萌感由角色和细腻反馈承担。

- 简洁但不空洞：保留功能完整性，减少同时出现的按钮和重复入口。
- 精致来自比例、对齐、字阶、留白、真实状态和细节，不依赖大量光效。
- Yuki 与周围背景自然融合，不做独立巨幅人物海报，不让角色压过任务内容。
- 多动态意味着操作反馈丰富、连续、有因果；不意味着页面始终晃动。
- 星辰元素可以出现，但必须稀疏、缓慢、低对比，留在背景空间。
- 少量英文西方诗歌提供艺术气息，可选莎士比亚十四行诗。核对原文与出处；不编造引文，不以中文古诗或中国元素装饰。
- 产品名称统一 Yuki / yuki / 雪；界面不再出现旧称“小橘”。历史数据目录及兼容标识不能仅为改名而破坏。

避免：满屏星空、星座连线、彩色粒子球、强光晕、霓虹渐变、沉重玻璃模糊、巨大营销标题、等权卡片堆砌、无意义胶囊标签、装饰英文挤占业务文字。

## 3. 信息架构

一级导航固定五项：**总览、角色、AI 助手、工具、设置**。新增功能优先进入现有栏目，不随意扩展一级导航。

| 栏目 | 内容归属与页面重点 |
| --- | --- |
| 总览 | 雪当前状态、显示隐藏和右下角放置；健康、安静与专注；时间天气、媒体、系统与事件摘要。优先回答“现在怎么样、可以做什么”。 |
| 角色 | 音乐互动、动作、外观、行为逻辑。动作有真实预览和分类；行为解释当前状态、触发原因与后续意图，不能把概率选择伪装成确定计划。 |
| AI 助手 | 本地模型与云端 API 配置入口；对话为主体，配置后置，附件靠近输入框。切页保留草稿和进行中的回复。 |
| 工具 | 时间管理、最近十条剪贴板、待办、划词翻译。以列表、详情和明确结果组织。 |
| 设置 | 通用偏好、主题与动态、快捷键、人设及长期记忆。按任务分组，显示保存结果和校验错误。 |

角色动作分类优先对应站立、坐下、趴着、睡眠，以及出生消失、飞行碰撞、音乐等场景。新增分类应反映实际动作资产，不用重复入口凑数量。

## 4. 版式与组件

- 侧栏建立稳定导航，子页使用清楚的标签与选中反馈。页面标题、说明与主操作关系稳定。
- 总览分清主次：角色、时间天气与状态协调成组，事件和工具在其后分层。不要每个指标都套一张大卡片。
- 角色页采用预览舞台与参数检查区；剪贴板等采用列表与详情；设置采用分组行；聊天保留足够正文空间。
- 每个任务区域突出一个主要操作；低频操作放入更多菜单或详情，危险操作独立区分。
- 复用一致的图标体系。纯图标控件提供名称或提示；标签不靠悬停才能理解。
- 所有输入提供可见标签、焦点、禁用和错误状态。弹窗支持合理的 Esc、焦点管理与返回路径。
- 页面不因轮询更新跳动，不因主题切换重置输入、滚动位置或布局。

### 可编辑工作区

长期方向是类似 Adobe 工作区的可调整面板、自定义页面和增删改区块。实际基线是可配置网格：排序、有限尺寸调整、自定义页面及保存取消；不是已经实现任意浮动、多窗格停靠引擎。

普通模式只操作内容；编辑模式才显示拖拽、缩放和配置工具。提供清楚的落点、边界及键盘替代方式；保存与取消分开，移除区块不删除底层待办等业务数据。新停靠能力必须作为独立实现验证，不能仅改文案宣称支持。

### 窗口

紧凑窗口与展开工作台可互换，展开适配显示器工作区，不默认强制全屏。现有文档基线：初始 1180×820，最小 880×640，标题栏 46px，侧栏约 144px；后续以实际宿主配置为准。窄窗口改列数和信息组织，不能只把整页等比缩小。检查 Windows 125%、150% 等 DPI 下的文字与控件。

## 5. 三主题与视觉参数

默认**银雾**，另有**雪白、星夜**；主题改变光线和材质，保持功能、布局及状态语义一致。顶部主题入口应容易发现，设置内保留完整选项；原生菜单和宠物气泡同步同一主题家族。

下表为现有 DESIGN.md 的基线摘要；精确令牌以该文件及实际 CSS 为准，不在新页面另建一套近似颜色。

| 语义 | 雪白 | 银雾 | 星夜 |
| --- | --- | --- | --- |
| 窗口底色 | #e6ecf1 | #ced8e1 | #0a111b |
| 内容表面 | #fcfdfe | #e8eef3 | #121c29 |
| 正文 | #243c50 | #263d50 | #e1eaf3 |
| 辅助文字 | #53697a | #4c6477 | #a6b8c9 |
| 边界 | #d2dfe8 | #b8cbda | #34485d |
| 蓝色强调 | #276e94 | #245f86 | #a7cce8 |

- 功能文字：Segoe UI Variable、Microsoft YaHei UI、Microsoft YaHei、sans-serif。
- Georgia 及斜体只用于少量字标、英文诗句等表达，不用于整页业务正文。
- 基线字阶：页面标题 26px、节标题 16px、正文 13px、标签 12px；关键内容不能持续缩小以塞入更多信息。
- 常用控件圆角约 6px，菜单约 9px，对话框约 12px；避免所有元素都变大圆角胶囊。
- 用邻近表面明度、细边界和间距区分层级，阴影只帮助理解悬浮与遮挡。
- 时钟等数字使用稳定数字宽度；颜色不是成功、失败或选中的唯一提示。

## 6. 动态与星尘

动效解释“发生了什么、从哪到哪、是否响应”。优先 transform 与 opacity，避免持续触发布局与高成本模糊。

| 动态 | 现有基线与使用规则 |
| --- | --- |
| 页面进入 | 180ms，约 3px 小幅位移与透明度变化；舒缓模式约 320ms |
| 导航、开关反馈 | 约 240ms，状态同步，不等待动画结束才响应 |
| 主题 | 约 300ms，整体协调过渡 |
| 区块重排 | 约 320ms FLIP，保持位置感 |
| 环境星尘 | 约 24s 的缓慢漂移，只在留白中低对比出现 |

以上是实现参考，不是所有新组件必须使用同一时长。不得把工作台“舒缓”设置用于任意改变桌宠动作速度。

必须支持减少动态、系统 prefers-reduced-motion 和粒子开关。专注时抑制装饰；页面隐藏时暂停环境动画和无必要的高频轮询，但不停止应继续运行的计时与提醒。粒子不遮文字、不拦点击、不跟随鼠标制造干扰；播放音频才显示音频活动，不能播放假电平。

## 7. 宠物右键菜单

保持简短：**状态、快捷对话、翻译、打开工作台、退出**。不复制整套设置，不堆动作库。

与工作台共享主题、细分隔线、小圆角和微弱星光。输入框便于立即聊天，回复可展开；中文输入法合成期间 Enter 不发送。打开和失焦处理必须兼顾输入法，不用粗暴自动隐藏破坏中文输入。文字和按钮清楚可读，菜单限制在屏幕工作区内。

## 8. 设计判断依据

- 渐进呈现：常用操作直接可见，复杂参数按需展开，减少用户同时判断的选项。
- 接近与对齐：相关内容靠近，稳定网格帮助扫描，减少不必要容器。
- 识别优于回忆：导航和重要功能名称明确，保留当前状态与操作上下文。
- 连续性：动画连接位置和状态变化，避免突然替换造成迷失。
- 一致性：同类操作采用同样的文案、状态和交互；主题之间不改变含义。
- 可控与可恢复：布局编辑可取消、通知可管理、动态可减少；错误说明下一步。

Refero 的借鉴重点是 Linear 的明度层级、Perplexity 的输入优先、teenage engineering 的对象与克制参数、Attio 的导航组织，以及 Raycast/Paste 的紧凑工具界面。借鉴秩序，不复制品牌配色、标识或营销页面。54 份研究基于当时可见截图与说明，不等于实际验证了原站完整交互。

## 9. 功能与真实性边界

- Electron + React/TypeScript 工作台与 Python/PySide6 桌宠是当前架构，不恢复 Tauri。
- 前端优化默认不改变桌宠物理、睡眠、动作触发或素材；相关改动另按用户要求进行。
- 当前动作以帧动画和程序微动为基础，不宣称已经完成 Live2D；换装依赖配套素材。
- 媒体状态展示不等于已有播放控制；“今日足迹”不是全天软件使用监测。天气、USB、下载等展示真实来源，缺失则显示不可用、未连接或空态。
- 本地与云端入口的实际连接机制先查代码，不把两个配置页写成两个独立活动会话。
- 长期记忆是用户管理的人设和记忆文本；不暗中从剪贴板、聊天附件或行为历史生成。
- 不展示、记录或硬编码密钥；保留已有密钥保护和用户数据兼容机制。
- 浏览器演示与真实宿主能力分开标识，不以演示值冒充已连接设备。

## 10. 后续开发验收

- 本次功能和原有入口完整，主次清楚，按钮无重复；未请求的架构和行为保持兼容。
- 雪白、银雾、星夜对比度和状态一致；紧凑、展开及目标 DPI 无遮挡、裁切和错误滚动。
- 键盘焦点、中文输入、长文本、空态、加载、断连和错误状态可用。
- 编辑区块、取消保存、切页、重启后数据恢复符合实际持久化规则。
- 减少动态、专注与隐藏状态有效；星尘和轮询不造成明显卡顿。
- 用真实页面截图审视布局与细节；依改动范围执行构建、测试和宿主验证，不继承旧文档的通过结论。
- 交付说明区分已验证、未实测及未来能力。新生成角色素材按用户要求先预览确认再应用。

### 2026-10-23 工作台尺寸适配补充
