# Yuki 正常步态参考修正

## 参考与应用范围

参考 [Physiopedia — The Gait Cycle](https://www.physio-pedia.com/The_Gait_Cycle)，2026-10-24 查阅。正常步行包括接地、负重、支撑中期、末期、离地以及摆腿；单腿支撑约占 60%，摆动约占 40%，完整周期有两段各约 10% 的双脚支撑。

本次将这些时序用于现有三分之四朝向程序步态，保留慢速、小步和原人物上身素材。不是重新生成一套动作图片，也没有修改攀爬或工作台。

## 修改

- 两腿相差半周期，各自支撑 60%、摆动 40%。全周期至少一脚接地，两次重量交接具有短暂双脚支撑。
- 接地脚随身体前进等量向后移动，保持桌面接触点稳定；摆腿采用端点速度与支撑期一致的 Hermite 曲线，抬脚曲线在离地和落地时垂直速度为零。
- 保留两条远近地面轨道、固定遮挡顺序和完整鞋子，避免鞋子逐帧拉伸。
- 去掉腿部切片中的裙边碎片，改用连续袜腿轮廓连接髋部、膝部与脚踝，避免旧的剪切映射在裙边下拉出三角形。袜腿局部为程序重绘；上身与鞋子复用原素材。
- 微调裙下隐藏的髋部锚点，使延长支撑期后的水平行走仍符合既定骨段长度上限。

## 验证

38 项测试通过，覆盖腿鞋连通、鞋底接触、骨段长度、支撑期落点、斜向移动、起停与宠物出入场。新增检查每腿 60% 接地、20% 双脚支撑、无双脚腾空以及离地/落地的位置与速度连续。

Windows 原生临时测试窗口完成四段行走，808 个采样，中位间隔 16.08ms，95 分位 20.20ms，最大 48.42ms，无倒退步或意外相位重置。测试程序自行关闭，未替换用户已运行的宠物进程。

### 用户确认的遮挡修正

用户最新纠正为近侧腿显得更长，远侧腿向后退。以此覆盖先前“短腿在前”的确认：长投影腿（图层 1）作为近侧，遮住较短的远侧腿（图层 0）；远侧鞋保留较小尺寸、较高的投影落点。保留两腿原有落脚轨迹，向左、向右行走均保持此层级。曾以不同髋部高度制造长短差的修改已撤销，两侧恢复同一骨盆高度。此修正只恢复远近透视，完整关节屈伸仍有后续优化空间。

随后用户明确身体朝向关系：“短的腿在靠近正面一端，长的在靠近背面”。基础布局调整为朝右时短腿在脸/胸口方向（右侧）、长腿在背部方向（左侧）；朝左时整体镜像。髋部水平锚点和对应脚步轨迹一起交换，避免只挪鞋造成斜拉。此处是两条步道的基础布局，行走周期中双脚仍交替迈出，不固定每帧的左右先后。

针对随后反馈的“拉伸过度”，运行时步幅从 40 缩至 28 逻辑像素（缩小 30%），脚部相对髋部的前后伸展相应收小；实际移动速度同比降低，使完整步行周期仍约 1.28 秒，避免短步幅导致频繁倒脚。两腿的基础位置、前后遮挡与人物上身尺寸保留。原烘焙 PNG 的元数据不改，运行时统一使用 `walk_stride` 的短步幅。预览脚本也改为读取实际步幅与速度；39 项回归检查通过。到达目的地测试依据实际速度计算所需时间，继续检查精确到达、不越界和相位连续。

这是现有素材的局部程序骨架优化。手臂仍来自原上身图片，鞋子暂未增加完整的脚跟—脚尖滚动，不能等同于逐帧重绘的完整人体步行动画。测试保证的是接触与连续性约束；最终自然程度仍需结合预览和实际体验判断。
