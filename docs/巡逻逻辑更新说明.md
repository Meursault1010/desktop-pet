# 巡逻逻辑更新说明

2026-10-24，按本次确认更新。本文替代旧方案中与以下规则冲突的部分。

## 移动与攀爬

空白区域允许横向和向下走动，不允许无支撑向上移动。普通散步结束只做短暂观察，不再固定接坐下。巡逻不把喝茶、原地长休息作为普通散步的随机替代项；图标附近仍允许有目的地坐着或趴着停留。

图标依靠分支接入左右背靠，以及原有的正反坐姿、正反趴姿和两种斜坐倚靠。需要上升到接触点时，先在当前高度走近，确认身体能够接触图标，再播放攀爬；休息结束后沿同一支撑爬回接近位置。太高而够不到的图标不能通过空走向上到达。

窗口侧框和屏幕侧边可以成为自主目标：先同高度走近，再抓住支撑向上爬，之后沿可用区间随机停留和移动。该任务结束后放开支撑，继续选目标；手动拖放停靠保持独立。窗口在接近期间移动或消失，会使旧接触点失效，不继续吸附旧位置。

主动巡逻中的图标故事冷却为45秒，同一图标冷却60秒，仍避免最近两个故事类型连续重复。普通日常陪伴保留原有较长冷却。活跃模式继续不受累计移动预算与低体力停走限制。

## 窗口前后关系

前后层级持续保持，只能在人物完全走出屏幕后由自主巡逻切换，不在窗口中央按秒数自动浮回前方。

随机安排一次出屏任务：横向走到屏幕外，确认整个宠物窗口已离开可见区域，切换自身窗口层级，再从随机侧边走回来。单屏可以在屏幕外改变返回高度；多屏仅选择不会把隐藏过程暴露在相邻屏幕上的侧边，保留同一高度，没有合适侧边时放弃本次出屏。

处于后方时允许被应用窗口完全挡住；没有强制定时出现。下一次出屏任务才会切回前方。程序只改变宠物自己的窗口层级与遮罩，不移动、激活或改变第三方应用窗口。窗口矩形裁切作为遮挡保障，圆角与透明边界仍可能存在近似。

结束巡逻会恢复用户原来的置顶偏好。拖动、聊天、暂停等打断仍然优先；出屏途中被打断会先将人物安全放回屏幕内，避免留在屏外。

## 已定位的旧问题

- 旧巡逻的依靠分支只随机左右背靠，坐趴素材虽然存在，却未接入该分支。
- 旧窗口和屏幕攀爬只由拖放或抛掷触发，自主巡逻没有进入入口。
- 旧图标候选要求整个路线矩形露出桌面，窗口会使很多原本可以接近的图标被排除。新主动巡逻只检查实际图标支撑区域；位于后方时允许互动被窗口遮住的图标。
- 手动停在图标上的角色会阻止再次开启巡逻。新手动开始指令会先离开已有的图标或边框附着，再启动巡逻。
