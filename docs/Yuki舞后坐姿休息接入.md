# Yuki 舞后坐姿休息

已新增 `dance-rest`（舞后坐下休息），接入正常舞蹈结束流程，同时加入工作台动作库。

## 素材

使用 shengtu-skill，以项目 `console-v2/图片/三视图.png`、舞蹈角色原画和已有坐姿作为参考，逐张生成 9 张关键帧。第 01 帧直接复用当前舞蹈的最后一张画面，避免切换时换姿势。

共 10 张关键帧：收步、轻轻喘气、放松呼气、屈膝、低蹲、坐下、调整坐姿、坐稳、坐姿吸气、闭眼眨眼。最终素材已转为透明背景，固定画布与接地高度，坐姿没有放大到站立高度。没有光流、轮廓变形或运行时图像补间。

生成时出现的错误坐姿及服装变化已舍弃，存于输出目录的 `rejected/`，不会加载进运行图集。生成使用 GPT 与 Gemini 各自配置的专用服务。

## 行为

- 自动随音乐跳舞正常完成完整舞句后，播放坐下休息。
- 手动播放非循环舞蹈，完整结束后同样进入休息。
- 休息期间只循环坐稳、吸气和短眨眼，不反复站起坐下。眨眼仅停留 130 毫秒。
- 按播放时随机安排的 4–6 次呼吸循环休息，再反向使用坐下关键帧起身，结束后回到待机。完整恢复过程约 17–29 秒；固定种子的交付预览为 21.686 秒。
- 拖拽、隐藏、暂停、睡眠、移动请求、聊天或切换其他动作具有优先权。被中断的舞蹈不会强行追加休息，也不会覆盖用户新选择的动作。
- 坐着时不自主行走；音乐会等待恢复结束和冷却后再启动下一轮。

## 检查与文件

检查透明背景、可见边缘裁切、接地高度、桌宠图集与工作台无损镜像一致性，以及舞蹈末帧与休息首帧的逐像素一致性。通过实际 DesktopPet 渲染器验证呼吸、眨眼、起身与中断，并运行相关音乐、动作、坐姿、显隐回归测试。

- `output/dance-rest-20261023/dance-rest-live-preview.webp`：实际桌宠渲染器的完整恢复预览。
- `output/dance-rest-20261023/review.jpg`：10 张最终关键帧。
- `output/dance-rest-20261023/asset-audit.json`：素材检查结果。
- `output/dance-rest-20261023/preview-timeline.json`：预览使用的帧顺序与时长。
- `console-v2/dance_recovery.py`：正常舞蹈结束与恢复动作的所有权、中断逻辑。
- `console-v2/action_player.py`：坐下、呼吸眨眼、起身的逐帧时间表。

重新装配现有原图时，在 `console-v2` 执行：

```powershell
.\.venv\Scripts\python.exe build_dance_rest.py
.\.venv\Scripts\python.exe preview_dance_rest.py
cd frontend
npm run build
```

以上重建不会请求生图服务。正在运行的 Yuki 需要重启才能加载新代码、动作目录和缓存。
