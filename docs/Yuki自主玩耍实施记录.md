# Yuki 自主玩耍与图标互动实施记录

更新日期：2026-10-23。对应《Yuki自主玩耍与桌面互动设计》，本文记录当前实现，不替代原设计的长期验收要求。

## 使用入口

保存并退出正在运行的旧实例，再通过项目现有启动入口启动。进入工作台 → 角色 → 行为逻辑。

- 自主走动：移动总许可；关闭后不派发自主玩耍路线。
- 自主玩耍：观察、探索、阅读、茶歇和休息的调度许可，默认开启。
- 自主图标互动：允许选择桌面图标作为目标，默认开启，与拖放即时吸附独立。
- 自主短句：允许稀疏的自主台词，关闭后不影响主动聊天。

页面展示当前行为、当前目标、下一步意图和原因。尚未选择任务时不显示虚构的倒计时。根目录 `start.bat` 调用现有 `start-workbench.bat`，读取已构建的工作台与项目 Python 后端；旧打包 EXE 不包含此次源码更新。本次没有修改启动入口，也没有结束用户正在运行的实例。

## 当前行为

清醒且没有用户操作、睡眠、音乐互动、物理飞行或其他高优先级任务时，偶尔选择一件小事。先观察，再沿可见的同屏路线走近，完成后休息。

图标故事包含走近观察、依靠、附近阅读、短距离绕行、部分遮挡探身，以及抓住边缘爬上坐稳后再爬下。空地故事包含小步散步、茶歇、趴着休息和慵懒侧滚后休息。正餐与零食沿用作息；正餐只有动作自然完成才记账。

图标顶部通过角色支撑锚点与图标可见表面计算位置，使用独立爬上/爬下动作和连续位移，不调用瞬移吸附。爬上结束、坐稳、爬下开始共用相同画面与布局，避免衔接偏移。图标空间不足时放弃该故事。

爬升和下降的位移跟随关键帧阶段：开始先抓稳，随后移动，最后到达支撑点；不会在抓握停留帧里持续上滑。缺少可靠图标轮廓或移动预算不足时改为旁边观察，并重新选择不遮挡名称的位置。坐稳时只叠加细微呼吸和下腿微动。

阅读停留 20–50 秒、坐姿停留 10–25 秒、趴姿停留 15–35 秒，只延长中性停留帧，保留进入、眨眼和起身段。自主侧滚执行一轮后趴着休息；手动动作和普通待机的侧滚周期不受此次限制。

睡眠仍由统一睡眠系统管理。进入正式睡眠前，可尝试一次走向附近可用图标，步行最多 6 秒、整个找位置过程最多 10 秒；扫描过期、路径失败或超时均原地入睡。具备图标图像时可局部遮挡营造躲在图标后的效果；图标移动、遮挡或尺寸变化后撤销遮罩，不追逐目标。唤醒后安静两分钟再入睡，沿用已确认的睡眠时段和唤醒条件。

新动作库分类为“自主玩耍”：探身看看你、坐着晃晃腿、靠近与站稳、抓稳后爬上图标、图标上坐稳休息、扶稳后爬下图标。部分动作供调度或桥接使用，不代表每个素材都会独立随机触发。

## 频率与安全约束

- 滚动十分钟移动预算：少动 30 秒、默认 60 秒、活跃 90 秒；连续走动上限 12 秒。
- 同故事冷却 8 分钟，最近两类不连续重复；同图标冷却 5 分钟，失败目标退避 2 分钟。
- 完成两件故事后安静休息 3–6 分钟；用户正在操作时多数机会退让。
- 依据距离、空间、目标新鲜度、休息需求与熟悉度选择目标；精力与好奇心仅为本机瞬态调度数据。
- 每秒核对目标，每 0.2 秒检查前方短路径。目标消失、遮挡、鼠标接近、路径超时或预算耗尽时取消。观察或步行阶段允许目标在同屏小范围移动后重规划一次，再次移动便放弃；执行接触动作时移动目标直接取消。
- 几何信息包含屏幕、可用区域、DPI 与人物尺寸，变化后撤销旧路线和接触状态。候选先做便宜筛选，最多检查 8 条路线，减少同步窗口探测。
- 菜单关闭后安静 10–20 秒，聊天结束后安静 30–60 秒，点击/拖拽释放后安静 20–40 秒；互动未结束时不提前消耗冷却。连续失败增加退避，最长 120 秒。
- 移动预算依据实际位置变化累计，原地停留不计入移动时间。吃饭到点时在故事的安全切换点收尾，睡眠可以接管自己拥有的自主动作与音乐动作。
- 动作使用代次标识区分控制权，取消旧任务不会停止用户刚选择的新动作。
- 图标只读，不打开、移动或修改文件；输入活动只读取系统空闲时长，不记录按键。

## 透明覆盖层误拦截修复

用户反馈露出桌面仍不巡逻后，实机确认 NVIDIA GeForce Overlay 保留了全屏可见窗口，但窗口全局透明度为 0；鼠标指示覆盖层则是分层、鼠标穿透窗口。旧遮挡算法只看窗口矩形，导致它们一直挡住桌面路径。

`desktop_icons.py` 现忽略全局透明度为 0 的分层窗口，以及鼠标穿透的分层覆盖层。普通窗口、仍可见的半透明窗口、无法确认透明度的窗口继续保守避让。不按应用名称放行 NVIDIA 的可见界面。

在同一真实桌面与同一人物区域对比：旧算法返回不可通行，修复后返回可通行。此修改属于 Python 后端，正在运行的进程不会自动热更新；需正常保存退出后由根目录 `start.bat` 重新启动，不需要重建前端。

## 侧滚动作与位移绑定

两组动作使用共享固定映射：`lazy-roll-toward` 向画面上方移动，`lazy-roll-away` 向画面下方移动。各自动作沿用自己的逐帧位移曲线，侧躺停留不移动、翻身时才移动，不随机交换方向或曲线。随机选择要播放哪组动作仍保留。

移除了空间不足时自动反转位移方向的旧回退。手动播放或普通待机靠近边界时，只缩短本方向位移，极端情况下为零；自主玩耍仍按既有规则放弃空间不足的候选。自主路线的距离也按动作绑定方向计算，避免传入相反符号导致反向滑行。

## 长时间未点击时撒娇

按用户确认，连续 5 分钟未点击人物后，在空闲动作槽播放现有动作库 `affection`（撒娇），不生成新素材、不位移、不附加台词。单击、双击、按住拖动和右键按下都从新的点击时刻重新计时；鼠标经过不算点击。启动时从零开始计时，不补播退出期间的撒娇。

使用自主玩耍的现有许可与优先级，睡眠、安静/暂停、聊天、菜单、拖拽、物理飞行、音乐和手动动作期间不抢占。正式睡眠时段不派发；已有动作自然结束后才有机会触发。每次触发后至少再等 5 分钟，错过机会不会累计队列。继续沿用自主玩耍开关，不新增界面控件。
