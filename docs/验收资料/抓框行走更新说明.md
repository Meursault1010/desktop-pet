# 抓框、行走与最近边缘附着更新

已于 2026-10-17 安装到桌面实际运行目录，并启动新版。

## 已实现

- 自动选择离宠物当前位置最近的可用落点，同时考虑已启用的窗口、屏幕范围。被上层窗口遮住的边段不作为停靠目标。
- 窗口左、右侧双手抓框，随机上下爬行、停顿和转向；下沿双手悬挂，身体与裙摆轻晃，双手保持原位；上沿使用转头坐姿或趴姿。
- 最大化、全屏窗口使用较近的内侧底角；只有距离相同时才考虑角落偏好。
- 随机散步、靠近图标、靠近边缘、回到底部均播放左右独立行走帧，按实际距离推进步频，限速移动。
- 窗口被用户移动时保持支撑姿态跟随，不计入自主行走或攀爬。目标关闭、最小化或失去可见支撑时释放，再重新寻找。
- 拖动、点击、动作和图标互动优先；暂停和安静模式停止自主走动与攀爬，保留待机呼吸。手动“去这里休息”“回到底部”仍可执行。

## 现在如何查看

当前保留了原设置：自然停靠已开启，等待时间 2 秒；“安静模式”和“暂停走动”均开启。要观察自动寻找边缘与爬行，请先关闭安静模式，再点击“继续走动”。

控制台依靠睡眠页下方的“自然停靠”可设置窗口/屏幕范围、等待时间，以及角落等距时的偏好。把她拖到窗口不同边缘附近，松开后等待手动操作冷却，即可更容易观察不同动作。手动交互后通常等待 20 秒；点击“离开边缘”后休息一分钟。

浏览器互动跟随浏览器外框；网页内部卡片、图片或滚动元素不属于本版边框。全屏网页使用安全角落。
