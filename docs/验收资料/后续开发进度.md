## 使用

打开控制台的「桌面互动」：

1. 选择桌面图标，再选择姿态卡片，点「去这里休息」。六种新姿态为转头坐姿、回眸坐姿、托腮趴姿、回头趴姿、朝你斜坐、侧背倚靠。原四种依靠姿态仍可使用。
2. 页面下方「自然停靠」中开启「自动寻找边缘」，即可跟随当前应用/浏览器窗口。新增开关默认关闭，迁移时保留已有使用习惯。可设置窗口/屏幕范围、左右角落偏好与 2～60 秒等待。
3. 普通窗口可坐或趴在上沿，顶部空间不足时倚靠侧沿；最大化/全屏时进入屏幕内侧角落，朝向屏幕中央。当前窗口移动、缩放时跟随；关闭、最小化或切换窗口后重新等待稳定落点。
4. 点击、拖动、跳跃、手动动作、隐藏会中断附着，手动操作后暂停自动附着 20 秒。点「离开边缘，休息一分钟」暂停 60 秒。图标互动优先于窗口停靠。
5. 若需覆盖应用/全屏窗口，保留「始终置顶」。程序遵守原有置顶偏好。
