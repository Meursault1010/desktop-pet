# 小橘：拖动反馈与即时吸附更新

已加入六个方向的拖动阻挡姿态。按住拖动时，双手会对准鼠标抓取点，视线朝对应方向，身体、头发和腿保持轻微挣动；松手恢复正常尺寸与姿态。

在工作台「我的小屋 → 陪伴模式」开启「拖放即时吸附」。同一开关也在「桌面互动 → 依靠偏好」，默认开启并自动保存。关闭后可自由拖放；拖动时的阻挡反应仍保留。

- 拖到窗口或浏览器外框附近，松手直接停靠：上沿坐或趴，侧边抓框，下沿悬挂。
- 拖到桌面图标附近，松手自动选择自然坐、趴、侧靠姿势。窗口遮住的图标不会吸附。
- 最大化或全屏页面只在附近角落停靠，远处松手不会跳到角落。
- 暂停走动、安静模式不妨碍手动拖放吸附；窗口移动时继续跟随。
- 「自动寻找边缘」继续控制她自行走过去停靠，与拖放开关分别设置。

浏览器停靠范围是浏览器窗口外框。页面内部卡片、滚动区域和图片边框不属于窗口边缘。
