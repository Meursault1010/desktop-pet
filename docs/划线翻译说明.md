# Yuki 划线翻译

## 使用

启动根目录 `start.bat`，在工作台的「桌面工具」开启「划线翻译」，也可以通过托盘菜单或 `Ctrl + Alt + T` 切换。每次启动默认关闭。

在其他软件中用鼠标选中文字或双击选词，译文会显示在选区附近的独立浮窗中，不抢键盘焦点。外语默认译为中文，中文默认译为英文；混合语言按文字比例判断。浮窗支持查看原文、复制译文、失败重试和关闭。单次最多 4000 字符。

图片或无法取词的软件：开启翻译模式后按 `Ctrl + Alt + O`，在鼠标所在显示器上框选文字区域；也可点击「框选文字翻译」。按 Esc 取消。

需要本地模型服务运行并加载 Qwen。模型连接沿用 AI 助手配置，翻译只接受 localhost / 127.0.0.1 / ::1 本机接口；不会自动切换到云端。

## 取词与隐私

1. 优先通过 Windows UI Automation 读取当前软件的文字选区。
2. 无选区时尝试模拟 Ctrl+C，临时保存剪贴板的各格式内容，并在剪贴板未被其他操作改变时尽量恢复。
3. 原软件不支持上述方式时，使用独立 OCR 框选；并非每个软件都能直接划线取词。

临时复制不写入 Yuki 的十条剪贴板历史。翻译不混入聊天历史，不持久保存翻译记录；OCR 截图仅在内存处理。开启模式后，普通选字也会触发本机翻译，不需要时请关闭。

终端程序和密码框禁止复制回退，避免 Ctrl+C 中断命令或读取密码。嵌入编辑器的终端、游戏、自绘控件及管理员权限窗口可能无法准确取词；请使用 OCR。剪贴板被其他程序同时修改、含特殊延迟渲染格式时，恢复仅为尽力而为。

## 实现与参考

- [Translate for Developers](https://github.com/SimplestBOT/translate-for-developers)（MIT）：参考系统选区优先、剪贴板回退及恢复的交互思路；没有复制其源码。
- [Pot](https://github.com/pot-app/pot-desktop)、[CopyTranslator](https://github.com/CopyTranslator/CopyTranslator)：参考跨软件取词与独立浮窗体验。

Yuki 使用独立 Windows C# 取词组件、Electron 安全隔离浮窗、现有离线 OCR 和本地 Qwen。UIA 查询放在有超时限制的子进程中；新选区替换旧请求，关闭模式停止监听和翻译。
