# Yuki 主题与动态预览

这是待确认的视觉研究，不修改正式 Electron 页面、桌宠动作或运行程序。图中天气、时间、使用统计等都是示例。

## 主题

- 雪白：近白纸面与冰蓝灰线条，适合白天与阅读。
- 银雾：减少纯白面积，以银蓝中性色组织层级，建议作为日常默认。
- 星夜：低亮度灰蓝，避免纯黑与耀眼霓虹，角色直接融入公共状态区。
- 三主题保持相同布局、字级与功能层级；宠物使用同一原始素材，不改色、不重新生成。

## 动态节奏

| 场景 | 设计值与规则 | 当前预览 |
| --- | --- | --- |
| 悬停、按下 | 100–140ms 改变边框和表面；按下最多偏移 1px | HTML 样例可体验 |
| 开关 | 160–200ms 平滑滑动，无夸张回弹 | HTML 样例可体验 |
| 主题 | 280–350ms 色彩与表面过渡 | HTML 与 GIF 可体验 |
| 栏目切换 | 140–180ms；最多 4px 位移，保留阅读位置 | 待实现 |
| 星辰 | 7 个稀疏星点，仅置于空白处；18–30 秒小幅漂移，亮度缓慢变化 | HTML 使用 24 秒、约 3px 漂移 |
| 区块编辑 | 进入编辑模式才显示手柄；拖动跟手，吸附反馈 100–160ms，不抖动 | 待实现 |
| 角色微动 | 沿用桌宠自身呼吸逻辑，避免整张人物周期缩放 | 本预览不改变角色素材 |

页面首次打开不自动轮换主题。GIF 为方便比较而循环展示三套主题，不代表正式页面会自行变色。星点不覆盖数据、诗句、按钮或人物。

## 安静与可访问性

HTML 提供暂停星点和减少动态；遵循系统 prefers-reduced-motion。专注样例暂停环境星点，保留操作反馈。正式版应在页面不可见时暂停环境动画，并通过真实 Electron 运行检查帧率和输入延迟，本次没有做正式程序性能结论。
