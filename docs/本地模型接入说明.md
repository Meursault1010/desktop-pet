# yuki · 雪：本地模型接入

日期：2026-10-17。

## 已接入的模型

- 模型：`empero-ai/Qwen3.8-4B-Distill-GGUF`。
- 本机文件：`~/.lmstudio/models/empero-ai/Qwen3.8-4B-Distill-GGUF/Qwen3.8-4B-Q4_K_M.gguf`，2,783,446,304 字节。
- LM Studio API 标识：`qwen3.8-4b-distill`。
- 许可证：发布者声明 Apache-2.0。权重本地运行，无按次 API 费用；仍有本机资源消耗。
- [量化模型卡](https://huggingface.co/empero-ai/Qwen3.8-4B-Distill-GGUF)、[原始模型卡](https://huggingface.co/empero-ai/Qwen3.8-4B)。

这是 Empero 发布的社区蒸馏模型，使用 Qwen3.5-4B 架构。作者称使用约 45,000 条 Qwen3.8-2.4T-A95B 教师轨迹进行全参数训练。不是千问官方发布的 Qwen3.8-4B。模型卡主要强调英文推理和数学，作者自报的 MMLU 提高、GSM8K 下降，不能据此推断中文陪伴体验全面优于原模型。本次核实为文本模型，LM Studio 返回 `vision: false`。

## 如何开始聊天

1. 打开本机已安装的 LM Studio/Bionic。
2. Bionic 左下角设置 → 本地模型 → 本地模型 API，开启“本地 API 服务器”。本机 Bionic 使用 `http://127.0.0.1:1235/v1`。
3. 运行项目根目录 `start.bat`，打开工作台“AI 助手”。yuki 自动检测 Bionic 的 1235 和经典版 LM Studio 的 1234 端口，并优先匹配已下载的 Qwen3.8-4B。
4. 输入文字，Enter 发送；Shift + Enter 换行。生成中可停止。“新对话”清除应用内的当前对话。

本次服务实际仅监听 `127.0.0.1:1235`。前端通过受检查的 Electron IPC 请求主进程，主进程访问本机服务。未放宽原有前端 CSP、Node 隔离或网页访问限制，也无需开启 CORS。

若出现未连接提示，先确认 LM Studio 本地模型 API 正在运行，再点“重新连接”。首次调用可由 LM Studio 按需加载模型。关闭 LM Studio 后聊天不可用，宠物原有桌面行为仍可使用。

## 当前行为和边界

- 角色提示词设定为雪 / yuki，温柔灵动、简洁中文交流，不编造工具执行结果。
- 流式显示正文，过滤 `<think>…</think>` 和独立 reasoning 字段。请求尝试 `enable_thinking: false`，但蒸馏模型是否完全遵循取决于模板和模型。纯思考达到上限时明确报错。
- 采样：temperature 0.6、top_p 0.95、top_k 20；单次生成最多 1536 tokens，180 秒超时。未照搬作者偏推理用途的 16384 输出长度。
- 输入最多 2000 字符；请求保留最近最多 10 条消息，并把历史压到约 3800 字符以内。主进程另有严格角色、数量和总长度检查，不接受网页传入 system 消息。
- 对话保存在当前工作台进程内存中，切换页面保留，退出清除；不提供长期记忆。LM Studio 是否保存服务日志受其自身设置控制。
- 本次未改变用户在 LM Studio 已有的模型加载参数。运行时报告加载上下文为 43264；若希望降低常驻资源占用，可在 LM Studio 单独调整到 4096～8192，再按需增加。
- 当前接入范围是文字聊天；没有语音、截图识别、文件访问、动作工具、联网或 Codex 控制。
