# 安装与使用本地模型

Yuki 可选安装一个本地 Qwen 模型。模型在自己的电脑上运行，不需要云端 API 密钥；首次启动会占用约 2.8 GB 磁盘空间和数 GB 内存。

## 安装内置模型

1. 打开 [Yuki 下载页](https://github.com/Meursault1010/desktop-pet/releases/latest)。
2. 下载应用 ZIP 和同一版本的两个模型卷（`part01`、`part02`），放在同一个下载目录。
3. 解压应用包。在解压出的 `yuki-win32-x64` 文件夹打开 PowerShell，运行以下命令；将路径改成实际下载目录：

   ```powershell
   .\install-yuki.ps1 -AssetsPath "$HOME\Downloads" -IncludeModel
   ```

4. 启动 Yuki，在“设置 → 通用”打开“启用内置模型”，再到“AI 助手”开始聊天。

安装脚本会合并两个模型卷并校验文件。只下载应用包并解压即可使用不带内置模型的轻量版。

## 连接自己的本地模型

1. 在 Ollama、LM Studio 或其他兼容 OpenAI API 的本地程序中加载模型并启动服务。
2. 打开「AI 助手 → 模型配置 → 本地模型」。可以扫描并选用已运行的服务，也可以手动填写程序显示的 API 地址。例如 Ollama 可填 `http://127.0.0.1:11434/v1`。
3. 点击「测试连接并读取模型」，选择或输入模型名称，再点「保存并使用」。服务要求验证时，再填写 API 密钥。

Yuki 下次启动会沿用已保存的连接。你也可以在「与雪对话」的模型菜单中切换本地模型，选择会自动保存。外部模型服务需要保持运行；如果先打开了 Yuki，启动服务后点击「重新连接模型」。

有多个常用模型时，可分别保存为「配置档案」。加载某个档案会启用对应连接，下次启动继续使用。

轻量版也可以连接自己的本地模型。已有模型文件可先在本地推理程序中加载，再把服务地址填入 Yuki。

## 连接云端 API

在「AI 助手 → 模型配置 → 云端 API」点击服务预设，填入该服务的 API 密钥，点「保存并使用」。Yuki 会自动填写服务地址与默认聊天模型。

预设包括 OpenAI、DeepSeek、Claude、Gemini、Kimi、通义千问、智谱 GLM、硅基流动、OpenRouter、Groq、Mistral 和 Grok。需要换模型时展开「连接设置」。其他兼容 OpenAI Chat Completions 的服务可选「自定义」，填写 HTTPS 地址和模型名称。地域或工作空间专用地址也通过「自定义」填写。

## 常见问题

- **提示未连接：**确认模型已安装并开启，或确认外部模型服务正在运行；检查地址和模型名称后重新连接。
- **模型回复慢：**本地推理速度取决于电脑硬件和模型设置；可以改用较小模型或云端服务。
- **没有图片理解：**内置 Qwen 是文本模型。Yuki 的 OCR 可在本机提取图片文字，再由你决定是否发送给 AI。
- **云端隐私：**使用云端模型时，发送的对话内容会传给所配置的服务。附件默认关闭授权，发送前可检查并确认。

模型来源、版本与许可见 [模型说明](../local-model/qwen/README.md) 和 [第三方许可](../THIRD-PARTY-NOTICES.md)。
