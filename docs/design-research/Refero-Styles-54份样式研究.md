## 范围与阅读方法

54 个不同样式详情 URL 全部读取成功，并均已对照其截图审阅，阅读设计概要、布局与组件目录；其中 8 份另看完整分辨率截图和组件细节。54 个 URL 无重复；同一品牌不同产品页明确标名，并不等于 54 家不同公司。

多数样本为宣传页或其内嵌产品截图。此次未测试原产品交互、未核验动态效果。Refero 的设计说明属于其测量与解释，不是品牌官方设计规范。所示产品名也不代表本次核实了该产品的发布日期。

## 归纳

优先参考 Linear 的暗色层级、Perplexity 的输入中心、teenage engineering 的对象优先、Attio 的标签与操作区分工。Dala 只提取低密度空间感。Raycast 与 Paste 以本次可见截图为限，不能推断完整产品行为。

Yuki 保持蓝白银、固定五栏、原角色素材和克制星辰。详细方案见 [Yuki Refero UI 设计文档](../Yuki-Refero-UI设计文档.md)。
