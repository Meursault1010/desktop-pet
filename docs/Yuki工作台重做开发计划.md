## 1. 产品目标与边界

Yuki 是住在桌面上的伙伴，同时提供轻量对话、时间管理与桌面辅助。工作台首先回答「雪现在怎么样」「我现在可以做什么」，需要深入时再进入动作、行为、工具和设置。

### 已确定要求

- 保持蓝、白、银的整体色调、雪花标识与现有角色身份，不重新设计 Yuki。
- 一级栏目只有五项：总览、角色、AI 助手、工具、设置。
- 角色包含音乐互动、动作、外观、行为逻辑；AI 助手区分本地模型与云端 API。
- 总览提供角色概况、健康／专注模式、时间天气、媒体与系统状态、每日使用总结及快捷控制。
- 工具包含时间管理、剪贴板、待办事项。用户说四个子栏但只列出三个，第四项暂建议采用现有「划线翻译」，待确认。
- 设置包含快捷键、人设及长期记忆；右键仅保留对话、翻译、打开工作台、简短状态、退出。
- 减少同时呈现的按钮，保留功能完整性；动态丰富但不干扰工作。
- 新增明确要求：动态星辰粒子营造冰冷、深沉、低调的未来感；页面区块支持类似 Adobe 工作区的拖动、缩放与停靠，并支持创建自定义页面、增删改区块。
- 沿用 Electron + React/TypeScript + Python/PySide6 桌宠后端，不恢复 Tauri 为新架构。
- 新生成角色图片先审核，确认前不接入正式动作库。

### 名称与范围约定

- 「纵览」暂统一为常用名称「总览」；「行为置换」按后文具体描述统一为「行为逻辑」。这两项是文案提案，可修改。
- 本次交付是规划文件，不修改运行中的界面、角色行为、启动入口或本机配置。
- 换装依赖实际配套素材，不承诺任意图片自动换装；完整 Live2D 建模另立任务。
- 不把 OCR 称为完整图像理解，不承诺任意云端 API 只填地址和 Key 都能运行。
- 不默认采集屏幕、键盘、窗口正文或网页内容来总结用户的一天。
- 不擅自增加付费生图、下载依赖、提交 Git 或推送 GitHub。

- 建议使用 hash 路由，例如 #/overview、#/character/actions、#/assistant/local、#/tools/time、#/settings，兼容 Electron 文件协议。
- 每个一级栏目记住上次子页；支持返回、直接定位与旧九页入口映射。

## 4. 设计美学与交互理论

### 4.1 视觉方向：冰冷、深沉、低调的星际工作区

让 Yuki 的角色状态成为产品辨识度。保留蓝白银，以更冷的蓝灰、更沉静的深蓝、微弱银光与缓慢星辰运动建立未来感。整体克制，不奢华、不珠宝化、不做炫技式科幻HUD。

浅色主题保留清冷留白，深色主题呈现深空蓝底与银蓝细节。深沉来自空间层次和节奏，不要求把所有主题改黑；冰冷来自环境材质，Yuki本身仍保留亲近感。

总览以真实角色和当下状态为焦点；对话页让文字与输入领先；工具页讲求效率；设置页安静、可扫描。不是让所有页面复制同一种大卡片构图。

### 4.2 色彩与主题提案

| 语义 | 基础色值 | 用途 |
|---|---|---|
| 雪白 | #F5F7FA | 工作区背景 |
| 纸白 | #FFFFFF | 主要内容表面 |
| 银灰 | #DCE4EB | 边界、细线与分隔 |
| 深蓝墨色 | #253B4E | 主文字与标题 |
| 蓝灰 | #657887 | 次级说明 |
| 冰蓝 | #377AA3 | 选择、链接、主要交互 |
| 浅冰蓝 | #EAF3F8 | 局部选中与氛围 |
| 玫红 | #B04760 | 错误与破坏性操作，非装饰色 |

建议四个主题候选：雪白〔默认〕、银雾〔偏中性〕、冰蓝〔偏冷〕、星夜〔深色〕。前三者调整底色与强调比例，不染色角色图；深色维持深蓝与清晰对比。主题共用语义 token，不随主题改变错误／警告的含义。

### 4.3 字体、网格与材质

- 中文优先 Microsoft YaHei UI／Microsoft YaHei，英文 UI 优先 Segoe UI Variable／Segoe UI；实际检查字体回退与中英文基线，不只声明字体名。
- 英文诗句使用 Georgia 等衬线字体，每个首屏至多一处，作为短题记，不遮盖操作。保留用户偏好的莎士比亚与西方诗歌，不加入中国元素。
- 正文建议 14–15px、辅助 12–13px、标题 24–28px、时钟 40–56px；最终以实际窗口、DPI 与缩放验证。
- 以 4px 为基础，主要间距 8／12／16／24／32px；侧栏约 176–208px，内容边距约 24–32px。
- 控件圆角约 8px、容器 12px、浮层 14–16px。优先分区、对齐和轻分隔，不把每条状态塞进独立卡片。
- 阴影仅服务浮层层级；银色通过明度差与细边缘呈现，不用金属贴图、霓虹描边或大面积玻璃模糊。
- 星辰集中在标题边缘与角色展示的一两处；设置和高密度阅读区减少装饰。

### 4.4 设计与行为依据

| 理论／原则 | 应用 | 验证 |
|---|---|---|
| 渐进披露 | 总览摘要、详情展开；模型高级参数折叠 | 初次进入可快速找到聊天、隐藏、专注 |
| Hick–Hyman 选择成本 | 五个稳定入口，同一区域一个主要动作 | 以找翻译、选动作、换模型检查路径 |
| Fitts 目标获取 | 主要按钮有足够面积，发送与计时固定位置 | 小窗口、高 DPI、键盘测试 |
| Gestalt 接近／共同区域 | 开关紧邻相关状态，分组表示真实关系 | 不读长帮助也能理解控制范围 |
| 状态可见性 | 连接、保存、更新时间、抑制原因清楚 | 断线、生成失败、后台恢复不误导 |
| 可逆性 | 外观预览、完成撤销、单项恢复默认 | 错误操作可恢复、草稿不丢 |
| 物体恒常与连续性 | 页面、菜单、预览过渡保持空间关系 | 不闪白、不跳高、不叠两个角色 |
| 注意力预算 | 通知分级，专注期间汇总低优先级事件 | 不让提醒和庆祝互相争夺注意 |

这些是设计依据，不是未经用户测试的效果保证。少按钮指减少同时呈现的选择，不是把有用功能藏到无法发现。

### 4.5 动效规范

| 场景 | 建议节奏 | 约束 |
|---|---|---|
| 开关／按钮 | 100–160ms | 不延迟业务执行，不大幅缩放 |
| 页签／页面切换 | 160–220ms | 不让每张卡片依次飞入 |
| 右键面板 | 120–160ms | 透明度与至多约4px位移 |
| 模式变化 | 180–280ms | 反馈与实际服务状态一致 |
| 角色呼吸 | 约4–7秒，继承现有动态 | 不叠加第二套缩放造成呼吸过度 |
| 星光 | 约10–18秒稀疏变化 | 阅读面静止，不持续闪烁 |
| 音频与数据 | 跟随真实信号 | 无声音不播放假频谱 |

隐藏／最小化暂停装饰与不可见预览；支持系统和应用的减少动态。关闭装饰不停止业务计时、待办和采样。聊天输入、拖拽、网络操作不等待动画结束。

### 4.6 动态星辰粒子：缓慢、稀疏、有纵深

- 背景分为远景星尘、少量中景星点、极少近景微光三层，以大小、透明度和缓慢视差表达纵深，不依赖强模糊与强发光。
- 星点以冷白、银灰、低饱和冰蓝为主；大部分近乎静止，少量缓慢漂移和明灭。不会像下雪、喷泉、烟花或亮片雨，也不做连续流星穿屏。
- 浅色主题粒子密度更低，优先显于页边和留白；星夜稍强但正文表面仍清晰稳定。不得在文字、表单、聊天内容上叠亮点。
- 建议默认全局只运行一个粒子层，面板不各自创建一套。初始预算可取常用窗口约20–40个远景点、3–6个中景点、1–2个缓慢微光，实际按可读性与性能调低，不视为固定数量要求。
- 单点亮度缓慢变化约12–24秒，漂移周期约30–90秒；整体没有明显重复节拍。禁止频繁闪烁、彩虹色、大片bloom、密集连线和夸张鼠标拖尾。
- 鼠标视差可选，默认极轻；输入、拖面板和缩放时减弱或暂停。粒子层不接收指针事件，不影响面板命中或焦点。
- 提供关闭／低／标准三档，不设置奢华高亮档；系统减少动态时使用静态星点或关闭。专注模式默认降低装饰活动。
- 渲染可优先采用单Canvas 2D，设帧率上限、DPR上限与自适应密度；无需要时不引入WebGL。低活动背景目标约24–30fps即可，不为星点强跑高刷新率。
- 隐藏窗口停止渲染循环，恢复后按时间重建相位，不补算每一帧；降低帧率与粒子数量不影响计时、通知、音乐或宠物后端。

### 4.7 可调整工作区：借鉴 Adobe 的面板逻辑

借鉴的是「面板有稳定身份、可以重新排列和停靠、布局可保存」的工作方式，不照搬Adobe品牌或复杂菜单。所有可独立呈现的内容块统一使用PanelShell，拥有轻标题栏、操作入口、内容区和尺寸约束。

#### 面板操作

- 普通模式默认锁定，确保点击、选字、聊天与滑块不会误拖。页面右上角的「自定义布局」进入编辑模式，完成后退出。
- 编辑模式标题栏显示拖柄与菜单，边缘出现缩放手柄；仅标题栏拖动，不整块拦截指针。按钮、文本输入、滚动条及角色预览保留原交互。
- 拖动显示位置占位与轻量吸附指示，支持重排、交换位置和停靠到允许区域。已有面板避免重叠遮挡；取消拖动恢复原位，Esc可取消。
- 缩放使用明确最小／最大尺寸；内容可切换紧凑、标准、展开布局，文字和按钮不随面板机械缩小。小于可用尺寸时限制继续缩小或转为摘要。
- 面板可折叠、隐藏、重命名显示标题、恢复默认大小；重命名不改变功能类型与数据来源。编辑菜单低调呈现，普通模式不常驻一圈按钮。
- 提供键盘与非拖拽替代操作：移到前／后、移到指定区域、选择尺寸、隐藏；焦点移动和变更结果可感知。
- 第一阶段采用窗口内吸附网格与分栏调整，保证可维护、无重叠。第二阶段可增加同类面板标签组与边栏停靠。独立于工作台之外的原生浮动窗口不包含在本次默认范围，避免引入多窗口焦点和生命周期问题。
- 工作型页面同样允许调整可独立面板的位置与尺寸；内部表单、消息和安全提示不可拆散。聊天输入与当前对话绑定，密钥表单不能拆成一个随意移动的公开小组件。

#### 自定义页面

- 总览内提供「默认总览」及自建页面页签，通过一个“+”创建，支持命名、复制、排序、设为启动页、删除与恢复默认。五个一级栏目不变。
- 创建时可选空白、陪伴、专注、电脑状态等模板。模板是布局初值，不改变功能开关与权限。
- 「添加区块」打开可搜索的区块库，按角色、时间、系统、工具分组，显示用途、可用性、支持尺寸与数据权限需求。
- 首期区块库建议包括：雪的此刻、快捷控制、模式、时钟、天气、媒体、CPU／内存、电源／U盘、最近事件、今日足迹、专注计时、待办摘要、剪贴板摘要、翻译开关、快捷聊天。
- 用户可增加、移除、换位置、改大小、改显示标题及调整该区块的展示选项；“删改区块”不等于允许执行任意脚本、编写新业务组件或修改原始数据结构。
- 新区块若需要活动监测或云端数据，仍走原权限设置；添加区块不会自动开启监测、发送数据或启动计时。
- 隐藏或移除只影响布局，不删除待办、聊天、记忆或历史，也不停止正在进行的专注与提醒。涉及停止服务时必须使用对应业务操作。
- 同一数据区块可多处引用，共用一个服务与业务状态；不重复启动采样、播放或请求。重复同类实例只允许有意义的不同展示配置，禁止布局制造多个同时控制同一业务的冲突会话。
- 敏感区块进入自定义页前清楚提示用途；记忆全文和Key编辑器不进入通用区块库，剪贴板摘要可选隐藏内容。
- 默认总览允许调整，但「恢复默认总览」始终可达；用户删空页面后出现添加区块入口，不成为无法操作的空白页。

#### 布局保存与恢复

- 布局独立于业务设置保存，包含schemaVersion、pageId、名称、默认页、断点、面板实例id、类型、位置、大小、折叠状态与展示配置。
- 拖动和缩放使用本地即时预览，松手后提交稳定布局；保存节流、原子落盘，不每移动1px就发IPC或写文件。
- 支持撤销／重做本次布局调整、完成、取消编辑、恢复页面默认；编辑会话中业务仍运行，取消只回滚布局，不回滚已发生的聊天和计时。
- 不同窗口宽度保存或派生合理布局，小窗口按阅读顺序压成单列；回到宽屏恢复宽屏布局，不用窄屏结果覆盖原布局。
- 删除自定义页面可撤销；导入／导出仅包含布局和展示配置，不包含Key、聊天、记忆、剪贴板或活动记录。
- 导入布局按内置区块注册表校验类型、数量、位置、尺寸与配置，不执行脚本、不加载任意远端组件。未知／已移除区块显示可修复占位，不导致全页崩溃。

#### 技术与验收

- 设WidgetRegistry与PanelShell，区分panel实例、业务数据、展示配置、布局数据。固定内置页与自定义页使用同一组件，避免两套功能长期分叉。
- 布局引擎先做小型技术样板，再决定现有成熟React网格／停靠库或自建实现；选型时核对维护、许可、React19兼容、键盘支持、缩放与高DPI表现，不在计划中未经验证就锁定依赖。
- 拖放使用Pointer Events与指针捕获、requestAnimationFrame合并更新，位移预览优先transform；ResizeObserver只观察必要容器，防止尺寸反馈循环。
- 计时、聊天流式与系统服务不因重排或移动跨区而卸载重启；区块使用稳定实例id，正在输入时不丢焦点和中文组合文字。
- 验收覆盖拖到边缘自动滚动、碰撞重排、取消、保存失败、撤销、删空、未知区块、重启恢复、宽窄切换、不同DPI、键盘替代操作与粒子降级。
- 性能基线同时测粒子开启／关闭、面板拖动／缩放、聊天流式与宠物拖拽并行。不能为背景氛围牺牲输入和拖拽流畅度。

## 5. 总览页面规格

### 5.1 内容顺序与布局

    顶部：总览／日期                         连接状态
    主区：雪的此刻、真实姿态预览             当前模式与专注进度
          显示或隐藏 · 放到右下角            日常／健康／专注
    次区：时间与天气                         正在播放
    下区：今日足迹与总结                     CPU／内存／电源／U盘
    底区：最近事件：下载、任务结果、待办提醒   开机启动状态

首屏突出角色、显示控制、模式与时间。允许纵向滚动，不强塞所有细节；今日足迹和电脑状态应露出标题或摘要以便发现。

### 5.2 雪的此刻与快捷控制

- 当前姿态、动作、生活时段与抑制原因靠近角色，不重复散落在侧栏、页脚、卡片中。
- 预览跟随真实姿态：熟睡显示睡姿与 zzz，而非状态写熟睡、图片仍站立。缺资源时使用可信静帧与说明。
- 显示／隐藏是一项明确控件；隐藏不是离线。
- 放到右下角需新增真实定位命令，不能把现有「回到底部」冒充实现。
- 按宠物所在屏幕可用工作区计算，避任务栏、留安全边距，使用实际角色包围盒，覆盖负坐标、多屏和混合 DPI。
- 定位先解除冲突的飞行／附着，建议短过渡，不长距离走路；具体过程在样板阶段确认。
- 总览只放主题快捷入口，自启只显示状态和进入设置的路径，避免重复主开关。

### 5.3 陪伴模式

日常、健康、专注是用户工作模式；睡眠是角色生活状态，不混为同一个开关。健康提醒是否允许穿透专注是独立偏好。

| 模式 | 默认行为建议 | 可调内容 |
|---|---|---|
| 日常 | 原有生活规律、随机待机、少量散步 | 活动、问候、吸附 |
| 健康 | 离屏、起身、饮水温和提醒，可稍后／跳过 | 类别、间隔、时段、渠道 |
| 专注 | 抑制主动问候、漫游和低优先级庆祝，保留呼吸和主动交互 | 时长、休息、健康与待办策略 |

健康提醒候选初值：离屏30分钟、起身60分钟、饮水90分钟，全部可改可关。这只是产品预设，不是医学标准。

专注与番茄钟共用会话。切换模式采用覆盖层，结束恢复之前偏好，不永久改写原 quiet／random_movement。锁屏和长时间离开不累计连续工作，恢复后不连发积压提醒。默认建议健康提醒在专注休息时汇总；明确截止待办遵循用户单独通知策略。

### 5.4 时间、天气与媒体

- 本地日期时间、可选秒数；等宽数字，更新不抖动布局。
- 天气显示城市、概况、温度、高低温、更新时间；失败保留缓存并标过期。空状态直接设城市，无需定位。
- 媒体显示曲名、艺人、应用、进度、播放状态；控制按钮仅在系统会话支持时启用。现有只有状态读取的场景不画假播放按钮。
- 多会话选择按需展开；无音乐显示等待状态，不做装饰性假频谱。总览与音乐互动共用同一媒体来源。

### 5.5 电脑状态与事件

- CPU 是系统整体使用率，差分采样；不以 Yuki 进程 CPU 或 load average 替代 Windows 总 CPU。
- 内存显示已用／总量及采样时间；说明系统口径，不伪造精度。
- 有电池才显示百分比；台式机显示交流电或不支持，不造100%。
- U盘显示新盘符与时间，不默认遍历盘内内容。
- 开机自启以发布版路径验证真实生效，支持关闭后核对系统注册状态。
- 下载、任务成功、任务失败分别标来源与时间；目录稳定事件叫「文件已就绪」，不是所有下载器的最终结果。
- CPU／内存建议2–5秒采样一次，后台降频；各页面共用服务，不切页重启多个采样器。

### 5.6 今日足迹与每日总结

先实现数据来源，再写生成总结。建议三层递进：

1. 本机基础统计：专注、待办完成、Yuki 事件与已记录时段，不需要读取其他软件内容。
2. 可选应用用时：主动开启后记录前台应用名称和活动时长，默认不收集窗口标题、网页地址、文档正文、键盘、屏幕或音频。
3. 可选模型总结：先预览结构化统计，再用本地模型生成；云端默认关闭，发送前确认数据和目的地。

- 范围为本地当天00:00到现在，但 Yuki 未启动前不可回溯；明确「已记录09:15至现在」。
- 区分电脑开启、用户活跃、应用前台、专注时长，休眠／锁屏／离开不重复计入。
- 总结只描述有证据的内容，不推断写了哪篇文章或认为娱乐代表失败。
- 支持暂停、排除应用、查看数据、删除当天／全部记录。建议默认只存当天，7／30天保留待确认。
- 跨午夜、时区变化、重启、系统时间调整需要专门测试。
- 无模型也能看本机统计；生成结果标时间与来源。
- 不自动把剪贴板、今日活动或总结写进长期记忆。

## 6. 角色：四个子栏目

### 6.1 音乐互动

- 首先解释是否听到、为什么没反应：会话、声音活动、节奏估计、当前策略与抑制原因。
- 提供主开关、灵敏度、强度、冷却，高级阈值折叠。
- 区分声音活动、节拍估计与真正音乐识别，不声称识别了并未实现的曲风。
- 睡眠、拖拽、飞行、附着、手动动作、专注中不强抢身体动作，原因可见。
- 预览和在桌面执行分开；未审核的华尔兹素材不列为已可用。
- 只分析本机播放音频，未经授权不启用麦克风、不上传原音频。

### 6.2 动作

「完整动作分组」和「待机姿态归属」是两种筛选维度，系统动作不强行塞进待机分类。

| 分组 | 内容 |
|---|---|
| 出现与离开 | 出生／出现、消失／退出 |
| 站立待机 | 已登记眨眼、等待、整理、伸懒腰等 |
| 坐姿待机 | 坐下、安静坐姿、可用坐姿活动 |
| 趴姿待机 | 趴下、趴卧停留、可用卧姿活动 |
| 睡眠 | 入睡、熟睡、唤醒、统一枕头与zzz |
| 移动与舞蹈 | 走路、侧滚、审核通过的舞蹈 |
| 拖拽与物理 | 拖拽反应、抛出、空中、四边碰撞、回弹、落地 |
| 附着与桌面互动 | 图标依靠／坐趴、窗口攀爬与悬挂 |
| 情绪与事件 | 害羞、摸头、庆祝、难过等 |

- 每项显示名称、用途、触发条件、姿态归属、素材／程序／混合实现、可用状态。
- 搜索与筛选按动作名、来源、可手动播放、系统触发；帧数只是辅助信息。
- 程序实现的出生／消失／碰撞也登记逻辑动作，不因没有独立PNG而漏列。
- 危险或依赖上下文的动作默认安全预览，预览消失不能退出应用，预览碰撞不能真实甩飞。
- 只有支持手动执行的动作才提供「在桌面演示」，并有停止／恢复自然待机。
- 同时只播放一个预览，缩略图静止，资源延迟加载；目录、后端触发点与发布包资源交叉核对。

### 6.3 外观

- 本体：大小、透明度、置顶、已安装服装与造型，不与工作台主题混淆。
- 气泡先设计雪白／冰蓝／星夜三种同结构样式，提供字体、字号、最大宽度、停留时间的即时样例。
- 语气来自设置中的人设；字体风格不能偷偷改写人设，不维护互相冲突的两套提示词。
- 长回复可收起／展开／到工作台查看，避免无限增高或遮挡关键区域。
- 睡眠zzz单独保留无框、可爱Q版字体、缓慢移动，不套入聊天气泡框。
- 换装资源包包含id、版本、支持动作、锚点与碰撞边界。缺动作明确告知，不混用不同服装凑数。
- 只有一套完整造型时诚实展示现状与导入条件，不生成虚假的可选服装。

### 6.4 行为逻辑

页面以「现在 → 接下来 → 为什么」组织：

- 现在：生活阶段、姿态、动作、来源、开始时间、模式、抑制项。
- 接下来：确定任务显示时间；尚未抽签的随机行为显示候选与大致窗口，标「倾向／未确定」，不造精确倒计时和概率。
- 为什么：睡眠、待机、散步、音乐、鼠标、附着、碰撞、聊天和事件按条件／行为／结束／例外展开。
- 优先级以现有调度核对后统一输出：直接交互与物理安全优先，其次手动／唤醒与必要提示，再由模式仲裁睡眠、音乐、事件与随机生活。UI不自创第二套规则。
- 增加只读近30条行为记录，显示触发与被抑制原因；修改高级规则校验并可恢复默认。

必须保持的已确认行为：睡眠00:00–07:00、13:00–14:00；点击、拖拽、消息、较大播放声音可唤醒，安静两分钟再睡。主要待机、少量散步；不恢复随机主动找边吸附，保留手动拖放与甩飞路径抓框。侧滚只在翻身帧位移，侧躺不漂移。自动待机有自然停留和冷却，不永久重复整段序列。

## 7. AI 助手

### 本地模型

- 对话为主体，输入框固定在对话区底部；连接条紧凑，详细参数展开。
- 保留地址、模型发现、连接测试、流式输出、停止、附件、清理会话。
- 服务未启动、无模型、超时、取消、OCR失败和附件截断有对应恢复路径。
- 模型名称用服务实际返回ID；不凭本机命名判断官方版本或多模态能力。
- 图片经OCR提取文字再交文本模型时明确标识；PDF／DOCX提取不等于能理解全部排版与图表。
- 空对话保留简短英文题记，开始交流后收起，让空间留给内容。

### 云端 API

- 核心输入为服务地址与Key；服务未提供默认模型时必须补模型ID，不能承诺所有服务只填两项即可用。
- 首期沿用 OpenAI 兼容 Chat Completions，厂商原生协议以后按适配器扩展。
- 本地与云端连接档案独立保存；切换地址不携带旧Key，切换后显示当前目的地。
- Key脱敏，支持替换／清除，沿用safeStorage；系统加密不可用时只保留当前会话，不写入前端持久化、日志或导出。
- 认证、限流、模型不支持、网络、服务器故障分别提示，技术详情按需展开。
- 本地／云端会话默认分离，不自动把本地历史、附件、活动总结、长期记忆转发云端。
- API接入不等于能控制电脑；模型命令执行与Codex联动另行定义工具权限和结果验证。

## 8. 工具

### 8.1 时间管理

- 番茄钟：工作、短休、长休、自定义轮次，开始／暂停／继续／结束／重置。
- 提供倒计时与正计时；建议首期只有一个活跃计时会话，避免并行提醒竞争。
- 主进程维护截止时间与持久状态，网页setInterval只刷新显示；关闭工作台后继续运行。
- 重启可恢复。建议倒计时按墙钟到期，专注有效时长排除电脑休眠；醒来只提示一次。
- 计时结束可系统通知、气泡、声音，默认温和；中途取消不计为完成一个番茄。
- 首页专注与本页共享状态，修改配置不让两处倒计时不一致。

### 8.2 剪贴板

- 保留十条不同文本、最近在前、点击复制、暂停、清空与会话内保存语义。
- 当前十条内搜索、长文本展开、显示时间，不把截断预览当完整内容。
- 不默认新增持久历史、无限收藏、图片和文件记录；这些属于另行确认的扩展。
- 不自动送给模型、总结或记忆；显式发送时显示目标与范围。
- 与翻译共享内部复制抑制机制，避免临时Ctrl+C污染记录或破坏用户剪贴板。

### 8.3 待办事项

- 标题、可选备注、日期时间、优先级；今天／未来／已完成筛选，编辑、完成、撤销、删除。
- 到期桌面提醒，提供完成／稍后／打开；编辑删除同步取消旧计划，以唯一提醒ID防重。
- 关闭工作台仍提醒；Yuki完全退出则不能保证准时。开机自启关闭时明确说明需要运行，不默认安装系统计划任务。
- 全屏／免打扰遵循策略，不强抢焦点；恢复后汇总错过提醒，不多条连弹。
- 本机持久保存。首期一次性任务，重复的每日／每周／工作日规则作为后续明确范围。

### 8.4 划线翻译〔第四项提案〕

- 保留系统选区优先、失败模拟复制并尽量恢复剪贴板、独立OCR框选。
- 外语译中文、中文译英文，选区附近独立浮窗；右键提供开关与框选入口。
- 工具页显示状态、快捷键、来源和故障说明；关闭立即停止监听，重启默认关闭先保留。
- 翻译使用的模型明确显示，不因选中云端聊天而静默改发云端。

## 9. 设置与长期记忆

| 分组 | 内容 |
|---|---|
| 通用 | 自启、关闭到托盘、启动是否显示工作台、位置恢复 |
| 工作台 | 主题、跟随系统、减少动态、星辰开关、密度与缩放 |
| 通知 | 健康／任务／专注／系统事件渠道、免打扰与全屏策略 |
| 快捷键 | 工作台、显示隐藏、专注、翻译、OCR等实际支持项 |
| 人设与长期记忆 | 人设、明确保存的事实、检索、编辑、删除、备份 |
| 隐私与数据 | 活动采集、保留期、排除、查看、删除、导出 |
| 诊断与版本 | 后端／模型／资源状态、脱敏日志、恢复默认、退出 |

快捷键支持录制、冲突检测、清除、恢复默认；系统注册失败不得假装保存成功。保留已有Ctrl+Alt+T与Ctrl+Alt+O，新默认键实机验证。中文输入法composition、输入框Enter与全局热键不冲突；退出释放注册。

长期记忆分三层：

1. 角色人设：身份、语气、称呼与边界，可预览、编辑、恢复默认。
2. 明确保存的事实：偏好、约定、事项，包含来源、时间、标签与启用状态。
3. 短期会话：对话上下文，不自动转为长期事实。

- 首期手动添加或「记住这件事」确认；模型提出候选记忆需确认，不把推断直接入库。
- 人设可编辑，但不能赋予不存在的屏幕访问或系统执行能力。
- 小规模先用关键词／标签检索和上下文预算，不为了功能名称强行上向量数据库。
- 冲突事实提示选择；删除／停用后的记忆不再进入新请求。清记忆与清会话分开，说明旧对话可能仍含相关内容。
- 云端使用记忆单独开关，不默认发送整库；导出主动触发且不含Key。
- 存储位置与加密状态明示，不承诺绝对安全；默认不记住剪贴板、活动监测与未经确认的私人信息。

## 10. 宠物右键面板

    yuki · 站立待机
    当前：喝茶   接下来：安静停留〔未确定时标倾向〕
    [ 想对雪说些什么？                       发送 ]
    翻译                                          >
    打开工作台
    -----------------------------------------------
    保存并退出

- 状态至多一两行，不放完整系统指标、动作库与设置。
- 对话支持中文输入法，生成可停止，Esc收起，草稿保留；若采用多行则Enter发送、Shift+Enter换行。
- 回复优先出现在宠物气泡，长内容可进工作台，不撑大菜单。
- 翻译一个子菜单，包含划线开关与OCR框选；细配置留工具页。
- 打开工作台复用现有窗口，不启动第二只宠物；退出走保存与正常关闭链路。
- 支持屏幕边角自动翻向、限高、多屏DPI，不因弹菜单触发拖拽或改变角色位置。
- 与工作台共用颜色、字号角色、间距和图标语义。首期优先精简现有Qt菜单，保护中文输入与焦点；改成Electron独立浮窗需另立技术任务，不混进美化步骤。

## 11. 跨功能规则

模式、计时、通知和角色状态共用权威服务。界面不维护第二套调度器。

| 场景 | 原则 |
|---|---|
| 熟睡时普通下载完成 | 记录，不主动叫醒 |
| 专注时U盘／庆祝事件 | 延后汇总，不抢动作 |
| 主动点击／拖拽／发消息 | 沿用唤醒逻辑，专注不阻止主动互动 |
| 飞行中收到音乐／提醒 | 物理安全优先，提示排队或仅通知 |
| 多条提醒同到期 | 合并、去重，避免动作与弹窗风暴 |
| 锁屏／休眠恢复 | 对时，汇总错过事件，不补跑离线动作 |
| 工作台关闭到托盘 | 服务继续，装饰暂停 |
| 完全退出 | 不宣称后台仍在监测，重启恢复保存状态 |

文案区分未开启、不支持、连接中、暂无数据、过期、执行中、失败；缺值不等于0，隐藏不等于离线，模型断开不等于宠物断开。

## 12. 技术结构与数据合同

### 前端目标结构

    src/app/                 五栏壳层、路由、页签
    src/features/overview/   角色、模式、系统、今日足迹
    src/features/character/  音乐、动作、外观、行为
    src/features/assistant/  本地、云端、对话、附件
    src/features/tools/      时间、剪贴板、待办、翻译
    src/features/settings/   通用、热键、人设、记忆、隐私
    src/components/ui/       统一基础控件
    src/design/              token、主题、字体、动效
    src/host/                继续隔离宿主API

按功能迁移，不一次搬空所有文件。App.tsx回归壳层，保留usePetController、命令队列与revision过滤，避免破坏设置顺序。

### 服务职责

- Electron main：系统监测、媒体、启动、通知、热键、计时、待办、活动统计、模型档案与记忆持久化。
- Python：角色渲染、动作、睡眠、物理、拖拽、附着及行为快照；UI只消费实际状态。
- renderer：显示和输入，无Node直接系统访问，不持有持久Key。
- desktop-services逐步拆成领域服务；IPC白名单、类型与范围校验、调用窗口校验继续保留。

### 建议新增合同

| 合同 | 必要字段 |
|---|---|
| CompanionSnapshot | revision、visible、posture、actionId、source、phase、mode、suppressedReasons |
| BehaviorForecast | scheduled／candidate／unknown、动作或候选、dueAt、原因、更新时间 |
| ModeSession | mode、startedAt、endsAt、pausedAt、有效时长、恢复策略 |
| SystemSnapshot | sampledAt、系统CPU、内存已用／总量、电源、U盘、媒体、错误 |
| Todo | id、标题、备注、dueAt、timezone、优先级、状态、reminderId、notifiedAt |
| MemoryEntry | id、内容、来源、标签、enabled、创建／更新时间 |
| DailyActivity | 本地日期、覆盖范围、活跃区间、专注会话、可选应用时长、事件 |
| ConnectionProfile | id、local／cloud、endpoint、model、keyPresent、能力；不返回Key |
| WorkspaceLayout | schemaVersion、pageId、name、defaultPage、breakpoint、面板实例布局与展示配置 |
| WidgetDefinition | type、标题、尺寸约束、支持能力、展示配置schema、权限要求；不含可执行远端代码 |

下一步行为需要后端排程、剩余冷却与确定程度；缺字段就新增合同，不能让前端猜精确时间。

### 持久化与升级

- 数据放现有Electron userData，不放源码、不提交Git。
- 小规模采用带schemaVersion的领域JSON，原子写入与备份；规模增大再评估SQLite，不提前引入复杂依赖。
- 设置、人设、记忆、待办、计时与用时分域保存，单个损坏不清空全部内容。
- 工作区布局单独保存，支持版本迁移、未知区块占位、恢复默认；业务数据不随区块移除而删除。
- 旧设置兼容迁移，保留回退；模式是覆盖层，不覆盖用户基础偏好。
- Key继续safeStorage／会话回退；新旧模型档案迁移不自动复制密钥到新目的地。
- 新旧UI不得以不兼容格式同时写同一文件；所有写入走同一服务。

## 13. 性能、可访问性与适配

- 验证1280×800、1024×720、800×600；现有最小窗口若更小也要覆盖，不能抬高门槛规避布局。
- 宽屏总览主辅双列，小窗口单列；主要控制仍在顶部。二级页签不截断名称，必要时可横向滚动并有明显提示。
- 页面尽量单一纵向滚动；聊天允许记录区独立滚动但输入框始终可见，避免双重滚动困住用户。
- 正文对比度目标至少4.5:1，重要图形／控件边界至少3:1；状态不能只靠颜色。
- 键盘可达、焦点可见、弹窗焦点返回、中文输入法与粘贴实测。
- 常规点击面积至少约36px，主要按钮／触控场景按44px，不能以极小图标换取少按钮的观感。
- 不可见动作暂停，列表缩略图不全量播放，数据推送合并。动画先用CSS和已有渲染器，确需复杂编排再评估依赖。
- 同机同场景比较重做前后CPU、内存、拖拽帧时间与输入延迟；无装饰常驻长任务是目标，具体预算在基线测量后确定，不虚报必达60fps。

不以固定天数冒充已评估工期；每阶段给可检查产物和通过条件。

### 重点验收

- 五栏与子页全可达，返回、筛选、草稿、计时不丢。
- 显示隐藏、右下角、大小、透明度、置顶、吸附、待机、睡眠、走路不退化。
- 拖拽、抛出、碰撞、回弹不被UI采样和预览干扰。
- 专注／健康／睡眠／音乐／待办冲突时无动作竞争和提醒风暴。
- 本地云端隔离，附件与记忆目的地明确，可取消与恢复。
- 翻译恢复剪贴板，十条历史不被内部临时复制污染。
- 锁屏、休眠、跨午夜、时区变更、断线、重启、重复启动可恢复。
- 无电池、无媒体、无模型、天气离线、长歌名／文件名、缺字体布局正常。
- 深色、小窗口、125%／150%／200%DPI和屏幕边角菜单通过。
- 星辰粒子支持关闭／降级／减少动态，后台停绘；拖面板和宠物时不增加卡顿。
- 可拖动缩放的内置面板、自定义页面增删改、布局撤销与重启恢复通过；移除区块不删业务数据、不停计时。
- 发布包与目录一致，不含Key、记忆、剪贴板、活动记录或测试用户数据。
