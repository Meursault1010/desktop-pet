# Yuki 走路与攀爬优化

本次以现有已确认素材为基础修改运行时动画，没有上传或生成新图片。

## 走路

- 保留慢速移动和距离驱动的左右脚交替周期，速度与迈步进度共用一个时钟。
- 髋部固定在裙摆下，腿部在髋、膝、踝之间分段驱动；鞋子保持刚性平移，支撑脚在桌面上的接地点保持固定。
- 膝盖主要向景深方向弯曲，限制屏幕上的侧向弯曲，避免短腿被弯成夸张折线。投影后的骨段不超过设定长度。
- 抬脚幅度从 16 降到 4 个素材像素；填补原裁切腿根的隐藏重叠区，上身保留轻微平衡动作。
- 不使用光流，不对整个人物逐帧缩放。

## 窗口侧边攀爬

- 采用各方向现有第一张姿势作为固定画面，仅局部驱动双臂；不再在运行时播放两张不同造型之间的旧插值序列。
- 双手交替抓握。每半周期的支撑手局部位移与人物整体位移相反，使其世界坐标稳定；另一只手平滑寻找下一抓点。
- 以有符号距离驱动，换方向不重置当前手部姿势；停止和暂停时冻结当前抓握状态。
- 每次拉动采用平滑发力曲线，在交接点减速，移动基准从 25 降至 12 个逻辑像素/秒，动画定时器从 33ms 改为 16ms。
- 校正左右侧上方手掌的边框接触位置。窗口本身移动仍不会推进攀爬步态。
- 使用有上限的姿势缓存，避免重复生成相同局部姿势。

## 图标攀上、爬下

保留现有抓握、拉起、跨过边缘、休息和爬下的素材流程。将原有分段线性位移替换为单调三次曲线；保留初始抓握停顿，减少各阶段速度突变。最后一帧保持终点，避免倒退。

## 验证

- 相关自动测试共 101 项通过，分进程运行均正常退出。
- 自动检查覆盖支撑脚的水平/斜向落点、双向抓握接触、换手连续性、膝部投影长度、腿脚连接、暂停、窗口跟随、图标攀爬流程和出生离场移动。
- 实际运行渲染预览：`output/yuki-contact-motion-preview.gif`；静态检查图：`output/yuki-contact-motion-review.png`。
- Windows 原生窗口四段移动检查完成：808 次采样，未发现倒退或步态时钟重置；中位帧间隔 16.05ms，95 分位 20.36ms，最大 37.7ms。属于当前机器短时检查，不能保证所有桌面负载下的帧率。
- 单帧离屏渲染 480 次采样，95 分位约 1.6ms；首次素材加载约 52ms，不能将首次加载当作稳定绘制耗时。

## 当前素材边界

这是局部分层驱动，并非完整 Live2D 骨骼模型。行走双臂尚未单独绑定；窗口攀爬的腿部、头发和服装采用固定源图，尚没有完整的交替蹬腿与独立发束惯性。后续若补充分层或关键姿势，需要先展示新图并经用户确认，再替换当前素材。
