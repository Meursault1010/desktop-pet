# yuki 项目总结

更新时间：2026-10-17。项目与桌宠正式名称：**yuki**。

## 项目定位与完成程度

yuki 是 Windows 透明桌面宠物与本地控制台项目。角色为白发、蓝眼、冰蓝裙的猫耳少女，设计目标是具有呼吸、视线、动作和接触关系的活泼陪伴感。角色依靠真实桌面图标和原生窗口边缘，不修改用户文件，也不改变其他窗口的位置。

目前版本为 1.1.0 Electron 兼容迁移版：Electron 控制台启动内置冻结 Python/PySide6 后端，素材为透明 PNG、动作图集和程序局部变形。已提供本地 Windows x64 便携目录，正式宠物窗口仍保留 PySide6；Electron PNG 原型尚未接管桌面行为。迁移与验证范围见 [Electron迁移总结](Electron迁移总结.md)。它不是完整 Live2D 骨骼模型。

## 已有功能

| 范围 | 当前行为 |
| --- | --- |
| 连续待机 | 呼吸、发丝微动、随机眨眼持续运行；暂停走动和安静模式不停止呼吸，隐藏时停止刷新 |
| 外观与行为 | 大小、不透明度、置顶、速度、活动频率、随机走动、暂停、安静、问候、跳跃、回到底部、隐藏与恢复默认 |
| 动作库 | 搜索、分类、桌面播放、暂停、循环、0.25～2 倍速度、逐帧时间轴；含关键帧动作与单帧姿势，不能将所有目录项称为完整流畅动画 |
| 图标互动 | 六种新增转头坐、回眸坐、托腮趴、回头趴、斜坐和侧背依靠，保留旧四种背靠姿势；可选图标、微调偏移、呼吸、时长和距离 |
| 自主行走 | 左右走路动画按实际移动距离推进，用于自主靠近目标，避免单纯滑移 |
| 自主停靠 | 按当前位置选择较近的可见窗口或屏幕边缘；侧边抓框随机爬行，下沿双手悬挂轻晃，上沿坐或趴 |
| 窗口跟随 | 目标移动或缩放时跟随，最小化或失效时释放；最大化、全屏采用内侧角落 |
| 拖动反馈 | 六方向姿态朝向鼠标抓取点，双手对准抓取点，身体、头发和腿轻微挣动；松手恢复普通显示范围 |
| 拖放即时吸附 | 可见图标优先，其次窗口/屏幕边沿；附近松手直接停靠，不先走路；暂停或安静模式仍可手动吸附 |
| 工作台 | 「我的小屋」与「桌面互动」共享「拖放即时吸附」总开关，默认开启并保存；「自动寻找边缘」独立控制自主寻找 |
| 生命周期 | 本地连接与错误状态、命令排序与偏好合并、单实例唤起、托盘显示隐藏与退出、断线处理 |

浏览器附着针对原生窗口外框，不能吸附网页内部任意卡片、图片或滚动区域。全屏页面仅在附近角落接受手动停靠，远处松手不会直接跳到角落。

## 图标分层必须保留的规则

依靠桌面图标时不再挖空裙摆或身体：头发、手、腿、鞋与裙摆始终完整不透明，目标图标只出现在人物轮廓之外。其他图标和全部文字同样不裁切宠物，宠物可以遮住文字。

图标由 Windows Shell 只读扫描，在后台更新，不能逐帧同步扫描。坐标需要从原生物理像素转换为 Qt 逻辑坐标；靠近边缘时根据角色 alpha 轮廓和呼吸包络换姿势或少量内移。

## 技术架构

```text
React 19 / TypeScript / Vite 控制台
  → Electron：命令白名单、托盘、单实例、子进程生命周期
    → UTF-8 JSONL stdin/stdout：请求、响应、状态推送
      → Python / PySide6：透明宠物窗口、设置、行为与绘制
        → Windows Shell / Win32：只读图标与窗口几何
```

没有用于控制宠物的 HTTP 服务或对外端口。stdout 仅输出协议，日志输出到 stderr；Qt 主线程执行窗口操作，后台任务负责扫描和输入投递。

核心模块位于 `console-v2/`：

| 模块 | 职责 |
| --- | --- |
| `main.py`、`pet_backend.py` | 控制层、命令校验、状态、进程与退出 |
| `pet.py`、`idle_animation.py`、`action_player.py` | 透明窗口、待机合成、确定性动作时序 |
| `settings_model.py` | 设置默认值、约束、持久保存 |
| `desktop_icons.py`、`icon_sleep.py`、`icon_pose_geometry.py` | 图标扫描、坐趴依靠、遮挡与接触点 |
| `locomotion.py` | 按距离推进走路/攀爬动画 |
| `window_edges.py`、`edge_geometry.py`、`edge_attachment.py` | 可见窗口、最近边缘、附着与跟随 |
| `drag_feedback.py`、`drop_attachment.py` | 抓取点变形、松手即时停靠协调 |
| `frontend/src/`、`frontend/electron/` | 控制台、状态队列、宿主适配、Electron 主进程和 preload |
| `frontend/src-tauri/` | 原 Rust/Tauri 宿主，保留回退 |

## 素材与制作方式

参考图和三视图固定角色身份、服装、比例与画风。曾使用 shengtu-skill 生成与修订姿态；原图、完整提示词和中间产物保存在 `action-work/`，运行图像在 `assets/`，接触表和动画检查在 `qa/`。本次整理不发起图片生成或上传。

- `assets/living-idle/`：连续待机相位和睁眼/半闭眼/闭眼图集。
- `assets/actions/`：动作 catalog、atlas、静帧与海报。
- `assets/icon-interactions/`：新增六种坐趴姿态及接触锚点。
- `assets/icon-sleep-v2/`：兼容背靠睡姿。
- `assets/motion-v2/`：左右走各六帧，左右攀爬和悬挂各二十四帧，包含程序派生帧。
- `assets/drag-resist/`：六方向阻挡姿态与固定双手接触点，运行时进行局部网格变形。

运行核心依赖 PySide6；Pillow/numpy/OpenCV 用于离线素材处理，不应变成用户运行时新增依赖。电子屏幕动作保留只取出一次、随后循环持屏操作段的时序。

## 验证证据与限制

整理前最后功能更新的记录：86 项 Python 回归、11 项前端测试通过，TypeScript/Vite 与 Tauri release 编译通过；原生临时窗口检查覆盖四边即时停靠、窗口移动跟随、最小化释放、全屏角落；实际安装目录的 42 项相关回归通过，24 个部署文件哈希一致。新版曾成功启动，工作台显示「本地已连接」，拖放即时吸附显示开启；真实界面切换与保存检查被用户操作中断，不能声称已完成该项实机验收。

本次文件整理后的独立检查结果见 [整理说明](整理记录/整理说明.md)。历史验收图片、GIF、提示词和更新说明集中在 `docs/验收资料/`；其名称与日期保留，作为历史记录。

尚需持续关注混合 DPI、多显示器、不同桌面图标大小、主题与窗口遮挡。依靠图标不裁切角色，因此不再需要按服装维护部位遮罩。旧动作中仍有少帧或单帧姿势，不应将程序变形等同于完整骨骼动画。

尚未实现 AI 聊天、语音、音乐响应、开机启动、全局快捷键、皮肤导入、签名安装器。Electron 兼容迁移已完成，最新自动化结果为 86 项 Python、22 项前端/Electron/PNG、便携版 10 组 E2E 通过；原有 623 个运行文件哈希未变。Electron 完全替代 PySide6 渲染、多屏混合 DPI 与休眠恢复仍待后续验收。
