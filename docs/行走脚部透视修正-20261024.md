# Yuki 行走脚部透视修正

## 问题

旧实现将双脚的鞋底都约束在素材 y=249 的同一条水平线上，抵消了三分之四视角中两脚的景深差。原图远侧鞋偏向观众，近侧鞋朝向画面右侧，直接拼合后两脚朝向也不一致。原接触数据来自放大后再缩小前的轮廓，与实际运行素材存在约 1 像素偏差。

## 本次修改

- 固定远侧腿与近侧腿身份及绘制顺序，先远后近。迈到身体前方不会交换远近层级。
- 远侧脚采用 y=241、近侧脚采用 y=249 的独立地面轨道。普通水平行走时，抬脚幅度小于两轨道的高度差，不会出现远近高低突然颠倒。
- 保持同一个方向向量驱动两只脚，支撑阶段的脚部局部位移与人物整体位移相抵，水平和斜向行走均保持世界落点。
- 复用近侧鞋的原有右向鞋面细节，制作远侧鞋的运行时图层；只在首次加载时统一缩小至 94%，不逐帧改变鞋子透视或拉伸鞋子。去掉原远侧鞋的鞋口残片，并补足相接的袜子区域。
- 按当前实际像素重新测量两只鞋的轮廓与接触点，避免使用失效的轮廓数据。
- 调整髋部与脚部横向位置，保留骨段长度约束和现有缓慢节奏。
- 修改生效于共用行走渲染器，包括普通移动、巡逻及出生离场中的实际走路阶段。没有替换独立的出生、消失姿势。

没有上传或生成新图片，没有修改攀爬、待机、UI、启动入口，也没有提交 Git。现有素材文件保留，远侧鞋在加载时组合。

## 能力边界

本次修正是现有二维素材的透视一致性和接触约束，不是三维重建。鞋子朝向在同一行走方向内保持稳定，尚没有每一步独立绘制的脚跟抬起、鞋底转动素材。
