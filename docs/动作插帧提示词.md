# 动作插帧提示词（可编辑）

用途：给现有动作补画中间姿态（替代光流形变）。每段先用下面的模板生成 1–4 张，再经「抠图 → 对齐 → 色彩匹配 → 验收」插入。

## 1. 优先级

按 `action-work/smooth/report.json` 的 `playback_peak` 排序，peak>40 的 28 段先做；`blink` 的眼皮段已确定不走插帧（见第 4 节）。

## 2. 每段插几张

`n = ceil(姿态差 / 25) − 1`，上限 6。姿态差取自同一份报告的 `original_jump`。

## 3. 身体姿态模板（已验证姿态递进可用，画风仍需先锁定）

> 参考图 1 = 姿态 A，参考图 2 = 姿态 B。画出 **4 格一排**：同一角色、同一画风、同一服装、同一取景、同一脚底线，纯浅灰背景、无阴影、无文字。
> 格 1：{A 到 B 的 25% 描述}；格 2：{50%}；格 3：{75%}；格 4：{B}
> 角色：白色长发、猫耳、左侧刘海雪花发饰；蓝色露肩连衣裙（一道白蕾丝边 + 一道蓝荷叶边）；白色及膝袜、蓝色玛丽珍鞋；3/4 视角朝右。
> 各格角色高度必须一致，不得改变体型比例。

注意：
- 一次只生成一条 4 格，不要 4×2；生成后先做画风核对（线宽、发量、脸部比例），差异明显就整条重出，不要逐格拼。
- 道具（放大镜、碟子、纸杯等）要跟手，不要悬空换位置。

### 2026-10-29 画风锁定轮实测（curious kf1→kf2）

- **整条 4 格重绘**：姿态递进和服装正确，但线宽更细、头发更圆、整体更淡（`action-work/inbetween-pilot/style-lock-strip.jpg`）。按 Lab 均值/标准差拉回色阶后仍然发白——因为生成图的白发占比更大，全局统计无法对齐局部结构。
- **对关键帧做局部编辑**（image-to-image，只改手臂与前倾）：身份、发型、发饰、服装细节保住了，但构图被放大、脸更正、颜色偏淡（`edit-25.jpg`）。
- **直方图匹配**（`edit-hist-match.jpg`）：把生成的帧逐通道直方图对齐到关键帧后，整体更灰、更平，比 Lab 匹配更差。
- 结论：在 256px 贴纸风素材上，AI 目前做不到“插入后看不出是另一张画”。两条可行路径：① 人工按本文件规格补画 2–4 张；② 接受 2–3 帧的轻微画风差异。

### 2026-10-29 落地后撤回（curious 第 1 段）

**结论：已撤下。** 用户反馈「有一帧画风和整体不同」——AI 插帧的脸更窄、眼睛更大更深、发量更多，与原画不是同一套画法。curious 现为 7 张关键姿态（2.06s），画风统一。下面的处理链保留，供人工补画后使用。

### 当时的处理记录

- 采用整条 4 格条的第 2–4 格作为 3 张插帧，`insert_between.py` 处理：rembg(isnet-anime) 抠图 → 按 25/50/75% 渐变对齐高度/脚底线/中心 → 只校正整体 Lab 色偏 → unsharp 追平关键帧边缘强度（15.8）；半透明边占比 0.02（关键帧 0.07，略硬）。
- 结果：`curious` 23→25 帧、2.06s 不变；接缝处仍有轻微线宽/发量差异，帧间差 60/41/40/60（光流版 66/63/33/66），观感对比见 `console-v2/action-work/inbetween-pilot/curious-flow-vs-drawn.gif`。
- 这条路径适合“接受轻微画风差异”的段落；要做到零接缝仍需人工补画。

## 4. 眼皮/表情：不要用 AI 插帧

- 256px 下模型画出的眼线比贴纸风细一个量级，缩回原尺寸后几乎消失。
- 用闭眼关键姿态的眼皮带做位移合成也会读成「虹膜上方多一条线」。
- 结论：眨眼、半睁、眯眼这类微表情直接切关键姿态（已在 `blink` 落地），靠时长而不是靠中间帧表现快慢。

## 5. 后处理

1. 抠图（rembg 或纯色底距离）；
2. 按角色高度等比缩放，脚底线对齐到关键姿态；
3. Lab 均值/标准差匹配到两端关键姿态；
4. 透明边 AA 与既有帧一致（半透明边占比 0.04 左右）。

## 6. 验收

| 检查 | 阈值 |
| --- | --- |
| 相邻帧姿态差 | ≤ 25 |
| 眼睛虹膜连通域 | = 1 |
| 轮廓宽度曲线 | 相邻帧突变 ≤ 10% |
| Lab 均值帧间差 | ≤ 0.5 |
| 播放 | 循环 3 次无闪烁、无重影 |

## 7. 插入方式

把画好的帧登记到 `build_smoothed_actions.py` 的 `DRAWN`：

```python
DRAWN = {
    ('curious', 0): ['action-work/drawn/curious_0_1.png',
                     'action-work/drawn/curious_0_2.png',
                     'action-work/drawn/curious_0_3.png'],
}
```

然后 `python build_smoothed_actions.py --actions curious --force --apply`，再 `python optimize_frontend_actions.py` 刷新控制台镜像。
