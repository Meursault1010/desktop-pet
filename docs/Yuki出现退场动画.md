# Yuki 出现与退场动画

已接入 `DesktopPet.present()`，启动、显示/隐藏和保存退出共用此流程。更新 Python 运行代码后，需要重启已经打开的 Yuki；无需重建前端。

- 出现：从当前显示器最近的左/右边缘探头，停留观察，然后移动到原位置，收步并接回原有站立待机。
- 消失：转身、走向边缘、停留回望，再完全移出边缘。隐藏后恢复原桌面坐标，防止下一次出现或保存位置时落在屏幕外。
- 中途反向切换：沿正在播放的姿势和路径倒放，不重新跳到起点。
- 支持尺寸设置，保留用户的不透明度设置；裁切到当前显示器可用桌面，避免露在相邻显示器上。

素材位于 `console-v2/assets/presence/`：17 张原关键帧，15 段相邻姿势补间，以及左右方向各 2 段待机衔接。每段包含 25 个采样，16ms 定时更新；运行时不计算光流，也不使用身体淡入淡出。补间采用同项目已有的双向光流、单源变形方法，19 段均通过步间变化与轮廓面积检查；检查结果见 `motion-report.json`。自动检查不能代替视觉检查。

## 重建与预览

在 `console-v2` 目录执行：

```powershell
.\.venv\Scripts\python.exe build_presence_motion.py
.\.venv\Scripts\python.exe preview_presence.py
```

预览：`output/yuki-presence-keyframes/presence-preview.gif`。它直接采样运行时控制器，同时展示左右边缘的出现和消失。

## 验证与素材限制

显隐、位置恢复、中途反向、多显示器坐标、物理、睡眠、巡游与姿势切换相关测试共 55 项通过。另完成了离屏渲染和预览抽帧检查。

本套原图是左右进出姿势，因此使用最近的水平边缘，不包含从上方或下方进入。左侧动作镜像播放，站立衔接恢复原待机方向。原行走帧的双腿差异较小，光流能平顺姿势变化，但不会凭空补出完整的交替步态；长距离移动仍有滑步感，进一步改善需要互补的左右脚落地、经过、抬脚素材或骨骼动画。当前没有修改平时自主行走的素材。
