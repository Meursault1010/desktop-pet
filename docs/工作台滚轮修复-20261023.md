# 工作台滚轮修复

实际复现：900×640 外窗下，渲染视口高度 604px，main 高度与内容高度均为 1048px，scrollTop 始终为 0。外壳裁剪溢出，导致下半页不可见；仅有 overflow:auto 无法保证产生滚动。

修复：在最终样式覆盖层为工作台 main 显式约束高度为视口减去 48px 标题栏，清除旧的自动外边距并保持纵向 auto 滚动。未拦截滚轮事件，不新增全局强制滚动处理，保留聊天、列表等内部原生滚动。

修复后相同窗口：main 556px、内容 1048px。Electron 真实 mouseWheel 输入可改变 scrollTop，滚到底部可看到页脚。验收使用独立用户目录，不替换用户数据。截图与日志位于 output/workbench-scroll 与 output/workbench-scroll-after.log。

源码和前端 dist 已更新；已启动的旧工作台需要保存退出再启动根目录 start.bat 加载新版。
