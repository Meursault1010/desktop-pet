# Yuki 四类待机与动作库

更新日期：2026-10-20。

## 使用

新版从项目根目录的 `start.bat` 打开。如果旧版正在运行，先在菜单选择“保存并退出”，再打开新版。待机动作受安静模式、暂停、拖拽、飞行、附着、聊天和手动动作的优先级限制。

工作台 → 动作库，新增 **睡觉、站立、坐下、趴着** 四个分类，另有“全部”和“其他动作”。按钮标注动作数量，卡片标注所属待机状态及用途；预览区说明它是自动待机、基础姿势、过渡还是互动反应。分类和预览不会主动改变桌面上的动作。

## 分类与行为

| 状态 | 已归入的动作 | 使用方式 |
| --- | --- | --- |
| 睡觉（3 项） | 闭眼入睡、睡觉·熟睡呼吸、睁眼唤醒 | 由作息与唤醒系统串联；每天 00:00–07:00、13:00–14:00 持续睡眠。被唤醒后安静两分钟再睡 |
| 站立（12 项） | 眨眼、梳头、整理衣服、看书、站姿阅读、喝茶、伸懒腰、等待、打哈欠、口袋电子屏幕、查看文件、跳跃 | 基础站立使用现有持续呼吸与随机眨眼；其余日常动作随机安排。站姿阅读静态素材保留手动预览，跳跃是偶发动作，未恢复“跳一下”按钮 |
| 坐下（7 项） | 端坐、放松坐、晃腿、进食、工作、两种坐姿阅读 | 三种坐姿休息约 24–38 秒；两种坐姿阅读约 18–28 秒，静态姿势也有轻微程序呼吸。进食在启用巡逻时由用餐/零食日程安排 |
| 趴着（4 项） | 托腮、放松趴姿、两个方向的慵懒侧滚 | 趴姿休息约 24–38 秒；侧滚保留逐帧控制的方向位移，滚完继续趴着休息，再恢复站立 |

点击、害羞、撒娇、庆祝等情绪和交互反应继续列在“其他动作”。抛掷和四种碰撞素材保留为物理系统专用，不混入随机待机。

## 调度

清醒时先从站立、坐下、趴着中安排一轮姿态，再从相应的未播放动作中抽取动作。仍参考时段偏好，并保留一轮不重复的动作袋，避免站姿素材较多而挤掉坐姿、趴姿。仅有部分姿态可用时，跳过不可用状态。

动作之间仍保留呼吸站立的安静间隔。坐姿、趴姿延长的是中性停留帧，眨眼、动作起身和落身的原有速度不变；播放不采用无限重复同一段动作。拖拽、手动播放和聊天仍可打断。

睡眠不参与清醒动作抽签，因此不会绕过“被唤醒后安静两分钟”的规则。入睡、熟睡、唤醒预览复用已认可的同一睡姿母版；退役旧睡觉图的插帧和对齐索引，防止动作库播放时混入旧头发或旧枕头。

## 实现与维护

- 共享分类：`console-v2/assets/actions/idle-states.json`，同步到 `frontend/public/actions/idle-states.json`。
- 运行时映射：`console-v2/idle_states.py`。状态接口新增 `idle` 字段；手动互动、飞行或附着与自动待机分别标识。
- 待机调度：`console-v2/idle_actions.py`、`console-v2/pet.py`。
- 动作库：`console-v2/frontend/src/components/ActionLibrary.tsx`。
- 素材同步：`python console-v2/sync_idle_library.py`，使用现有本地图片，无需外部生图。

现有素材的站立、坐下和趴下过渡继续使用原动画及程序插帧，没有新增完整骨骼绑定或 Live2D 模型。
