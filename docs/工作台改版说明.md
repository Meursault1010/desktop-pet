# yuki 工作台改版说明

日期：2026-10-17。基于 yuki v1.1.0 Electron 兼容迁移版，本次为本地工作台改版，未创建新的版本标签、Git 提交或 GitHub Release。

## 交付结论

完成蓝、白、银配色的九页工作台，支持银白浅色与深海深色主题。保留现有 Electron 宿主、preload、白名单 IPC、Python sidecar 和 PySide6 透明宠物窗口。本次没有恢复 Tauri 主架构，也没有替换桌宠行为系统。

总览以角色展示、真实状态和三个常用开关为中心；完整动作控制集中在动作库；图标与边缘的详细选项集中在行为页的展开面板。移除新版工作台的“跳一下”手动入口。跳跃素材、底层协议、原有点击行为和旧版回退代码继续保留。

音乐互动、AI 助手、工具完成视觉框架，明确标记尚未接入，没有模拟对话、采集音频或执行工具。没有实现本轮提及的随机待机调度、移动翻滚、新巡逻、单击/双击反应或闲置抓鼠标等新行为。

视觉使用雾白画布、银灰细线、冰蓝强调色和深蓝侧栏；展示区采用透明 PNG、低亮度轨道与少量微光。提供页面淡入、悬停反馈、状态呼吸、慢速粒子、频谱与轻微浮动。设置支持关闭动态、粒子和光晕；同时遵循系统 `prefers-reduced-motion`。角色展示复用现有 PngRenderer 的呼吸与眨眼；后台隐藏时释放该预览播放器。

帧率没有对应后端遥测，显示“FPS 未采集”；时长仅统计“工作台会话”，不冒充桌宠运行时长。总览角色为待机素材预览，旁边状态来自桌宠，二者不是实时画面镜像。浏览器 demo 明确显示预览身份。

保留原生标题栏与窗口控制。现有 Electron main/preload、窗口管理、安全参数、托盘和单实例实现未被重写。

## 启动与构建

日常运行：根目录 `start.bat`，优先打开已更新的 `releases/electron/yuki-win32-x64/yuki.exe`。必须保留整个便携目录。

开发运行（在 `console-v2/frontend`）：

```powershell
npm.cmd run build
npm.cmd run electron
```

源码开发需安装 Electron 依赖，并由 `install-electron.bat` 准备 Python，或设置 `PET_PYTHON` 指向包含 PySide6 的解释器。便携版内含冻结后端，无需另外安装 Python。

完整构建（项目根目录）：

```powershell
./build-electron.ps1 -SkipInstall
```

`-SkipInstall` 适用于依赖已准备完成的本机。首次构建使用 `./build-electron.ps1`。仅前端更改且冻结后端已存在时，可在 frontend 运行 `npm.cmd run build` 与 `npm.cmd run package:electron`。

所有条目沿用既有桌面播放协议。资源与时序已验证，端到端抽测口袋电子屏幕的桌面播放/停止和看书的本地预览，不宣称逐一重新人工审核了 31 组动作。打滚仍沿用现有动画播放逻辑，没有新增移动轨迹；挥手未登记到当前 catalog，未编造为可播放条目。

## 后续接入

Live2D 需要合法可用的 `.model3.json`、`.moc3`、贴图，以及 motions/expressions/physics 等配套文件，之后实现现有 PetRenderer 的适配器并验证透明窗口与交互。当前没有嵌入 Live2D SDK。

音乐互动需要先选择麦克风或系统回环来源，完成相应 Windows/Electron 权限与显式开始/暂停/停止流程，再实现 `AudioFeatureSource`。当前只展示示意频谱，未请求权限。

本地模型可通过独立本地推理服务接入现有 `ConversationProvider`，后续支持 GGUF、流式输出、取消和动作触发；云端模型由受控服务适配，凭据不能写入前端或日志。语音继续通过现有 `SpeechProvider` 预留接口扩展。当前没有服务请求或假回复。

Codex/快捷工具后续须通过专用适配器接入；工具必须注册白名单、校验参数、限制授权路径与 URL，并具备确认、取消、超时和审计。当前工具卡片没有文件、Shell 或网络执行入口，未扩大现有 preload 权限。

自动随机待机、移动翻滚、新巡逻和鼠标反应需要另行设计情境与优先级、移动轨迹、冷却和打断规则，本次仅为这些能力预留清楚的界面位置。
