## 0.5 翻顶动作设计（2026-10-29 用户确认"对了"）

从侧爬翻到顶端坐下的过渡编排，**已确认**，后续按此出帧。

**素材与方位**
- 侧爬用 `climb-left`（运行时窗口左边缘对应它）：人在**窗外**，手抓左边框，脚蹬窗面。
- 坐姿用 `sit-front`：3/4 朝画面左，屁股坐在顶沿，腿垂在窗面前。
- 硬约束（真实素材实测，单位：256 动作画布换算到设计画布 ×1.25）：肩→手 ≈86px，髋→脚 ≈106px。

**六拍**
| 拍 | 时间 | 手 | 髋/身体 | 脚 |
| --- | --- | --- | --- | --- |
| B0 | 0.20 | 双手竖框（一高一低） | 挂在框外 | 一脚低踏窗、一脚屈膝抬高 |
| B1 | 0.30 | 仍竖框，引体 | 升高一格 | 两脚沿窗面交替蹬上 |
| B2 | 0.40 | 两只手绕角按到**顶沿** | 身体挂沿下，头过沿口 | 收脚离墙、屈膝 |
| B3 | 0.48 | 双手撑沿（肩升到手以上） | 髋提到角 | 双膝收在身下 |
| B4 | 0.56 | 仍撑沿 | 双腿摆到**窗面前方** | 腿在窗前、脚不越框外 |
| B5 | 0.66 | 一手撑沿、一手放开 | 屁股落到**顶沿**（角点右约 50px） | 垂在窗前 |
| B6 | 0.78 | 放手 | `sit-front` 坐稳 | 垂腿 |

**关键约束**
1. 换手到顶沿必须发生在**引体之后**（肩离沿 ≤45px 时才够得到），否则手臂被拉长。
2. 她全程在**窗外**；末尾是整个人坐在顶边上，不是半悬在角上。
3. 手在屁股落沿后才松开，重心由手交给屁股。
4. 末帧对齐 `sit-front` 的 `support_contact`，运行时可直接切坐姿。

**验证脚本**：`console-v2/work/corner-climb-v2/top_mount_design.py`（含肩→手距离自检，>92px 会报警），输出 `top-mount-beats.png`、`top-mount-animatic.gif`。

**待画**：B2「双手上顶沿」、B3「撑起提髋」两张；B4/B5 可用 `sit-front` 派生。

## 1. 目标

用户要求：Yuki 从窗口左上角爬上去、跨过边沿、坐到窗沿上，动作**连贯**、接触可信；允许重新设计，优先保证连贯，其次速度。

当前采用**用现有 Live2D 模型拆件做 2D 剪贴骨骼 + PIL 逐帧合成**的离线验证路线，不是 AI 逐帧，也不是原生 Live2D 动画。

## 2. 现状（结论先行）

- 已完成可播放动作：`window-climb-live2d-v4.gif`，720×720，3.37MB，67 帧 @25fps（0–2.64s）+ 末帧定格 0.68s，总长 3.32s（GIF 优化会合并重复定格帧）。
- 一键复现：`cd console-v2/work/corner-climb-v2 && python climb_timeline.py`（约 50–60s），会重新生成 v4 GIF、`strip-v4.png`、`last-frame-v4.png`。
- 动作流程：发顶露出 → 眼睛 → 脸 + 双手扒住窗沿 → 预压 → 撑起 → 裙摆/头发从窗沿"倒"下来 → 落座（膝盖、袜鞋垂下）→ 定格。
- 自评：
  - 可用：头部 reveal、手扒沿、裙摆/头发倒下来、落座后的膝盖与垂腿。
  - 偏弱：拉撑段（1.06–1.80s）只有肩膀/袖口和手在沿上，前臂藏在窗后，近看/慢放会像"手悬空"；静帧仍带一点"站在窗前"的歧义。
- 建议先让用户看 v4 GIF 决定是否接受，再谈接入。

## 3. 为什么走剪贴骨骼（历史决策，避免重走）

1. **AI 单排多格出帧不可用**：相位、画风、比例不稳定，独立帧不能当动画。历史提示词见 `docs/yuki-corner-climb-prompts.md`。
2. **模型尺寸决定了两条硬约束**（内部场景 1800×1800）：
   - 头/发总宽约 597px，手臂全长仅 184px（肩→腕），**发宽 > 臂展**。任何抬到胸前的膝盖都会被头发完全挡住，除非画到 ±250 之外（视觉上等于把腿撇到体外）。因此**放弃"单膝勾住窗沿"**，改为"手扒沿 + 躯干撑起 + 裙摆倒下来"。
   - 手臂按 IK 摆到窗沿时，会露出腋下空洞或肘部外拐（拆件没有腋下几何补面）。最终改为**全程使用模型原生 rest 手臂**，只让手出现在窗沿上，前臂在窗后由裁剪线隐藏。

## 4. 场景与坐标系

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `SCENE` | 1800 | 内部画布，输出缩到 900/720 |
| `E` | 940 | 窗沿前唇（title bar 顶） |
| `WALL` | `E - 42 = 898` | 窗沿后缘；角色藏在窗后的裁剪线 |
| `PANEL_X` | 840 | 窗口左边缘 |
| `CX` | 1320 | 角色中心 |
| `S` | 0.478 | part 像素 → scene 像素 |

- 窗沿结构：`E-42..E+8` 顶面亮带 + 标题栏（`E+6..E+56`）+ 交通灯；顶面亮带是"她坐在上面"的关键，不能省。
- 内容：左侧栏 + 白色内容卡 + 列表线 + 玻璃反光，用来提供"这是屏幕"的尺度；没有内容时，白色窗面会被读成白色地板。
- 背景：深蓝渐变 + 中心光晕 + 面板投影 + 环境光池。

## 5. 关键实现

### 5.1 拆件与补件

- `split_arm()`：用肘/腕平面把 `arm_l/r` 拆成 `upper / fore / hand`；hand 用**掌心径向羽化**抠出，避免腕部出现楔形刀口。
- `_make_thigh()`：合成 70×96 的膝盖/大腿胶囊（肤色 + 深紫外轮廓 + 粉色阴影 + 膝褶），放在裙摆下、袜口上。**没有它，裙摆到袜口之间没有腿，坐姿会读成站立**。
- 头部：`head-hybrid3.png` 为基准；和 `backhair.png` 一起整体下移 18px 补颈缝；后发不用运行时版本，避免盖住脸。

### 5.2 落座姿态

- `root = E + 10`；裙 `(sx 1.07, sy 0.93, tilt 2.5°)`。
- 双腿 `l (dx 12, dy 32, rot 17)`、`r (dx -10, dy 42, rot -10)`：`dy` 把腿整体下移，让膝盖胶囊露在裙摆下，形成"垂腿"。
- 双手落在 rest 掌心 `(CX ± 123, E + 94)`，与 rest 手臂对齐。

### 5.3 裁剪与跨边过渡

- `behind`：char + arms 用 `alpha_clip_below(WALL)`，窗后部分全部隐藏。
- `crossing`：`alpha_reveal_below(WALL, wipe, feather=18)` 从上往下"倒"出裙摆、头发、腿；`wipe` 是露出深度（0→760）。
- `front`：不裁。
- 手始终画在最前（不裁），在 0.86–0.98s 淡入并"从沿下升上来"。
- 手部路径（最新）：1.50/1.64 仍在沿上 `(±124, 928)` → 1.80 `(±130, 986)` → 1.94 `(±124, 1026)` → 2.04+ rest 掌心 `(±123, 1034)`。

### 5.4 阴影（最大的坑）

- `body_shadow()` 双层：紧层 0.62α、模糊 6px；软层 0.26α、模糊 22px；颜色 `(64, 96, 138)`，偏移 `(10, 12)` / `(16, 20)`。
- **不能用近黑色**。角色手臂与身体之间的凹槽会被投影填满，深色版本会被读成"黑色破洞"（排查花了一轮以上）。
- 阴影遮罩从 `E-44` 起；手部另有独立接触阴影（沿上用 `py+8..26`）。

### 5.5 时间轴

`climb_timeline.KEYS` 共 17 个关键帧，Catmull-Rom 插值；`mode` 按关键帧段起点离散切换（`arms_front`/`arms_alpha` 已不再影响合成，属死字段）。

| 时间 | 事件 |
| --- | --- |
| 0.00 | 发顶刚过沿 |
| 0.50 | 眼睛露出 |
| 0.98 | 双手扒住窗沿 |
| 1.18 | 预压（下沉、低头） |
| 1.34 | 撑起 |
| 1.50–1.64 | 身体到最高点，双手仍按在沿上 |
| 1.64–1.94 | 跨边，`wipe` 30→540，裙摆/头发/腿露出 |
| 2.04 | 落座（裙压缩、回弹） |
| 2.18–2.62 | 回弹定格 |

- 手臂：`arms_rest=True` 全程使用模型 rest 姿态（跟随 lean）；`arms_on=False`。IK 分支代码仍在，但未启用。
- 待机细节：发丝摆动 `hair`、头部 `head`、裙摆 `tilt` 都有关键帧；落座时 `head -6°`、`hair -2.2°`，回弹时反向。

## 6. 验证与量化

- 67 帧 @25fps；逐帧差异（300×300 灰度平均绝对差）中位数 1.0。
- 1.84–2.00s 差异 2.45–2.77（约 2.5× 中位数），对应跨边 + 裙摆倒下，是主动作，不是跳变。
- 0.72–1.0s 手部淡入、1.8s 手臂切换处**未出现**差异尖峰。
- 导出：720×720、256 色全局调色板、无抖动 → 3.37MB；900×900 + 抖动版本曾达 13.5MB，已弃用。

## 7. 已知问题（按优先级）

1. **拉撑段手臂大部分不可见**（1.06–1.80s）：只有手和少量袖口在沿上，前臂在窗后。远景 25fps 不明显，慢放会像悬空。要彻底解决需补"肩→腕"手臂合成件，再开 IK。
2. **静帧"站立"歧义**：正面、长裙、腿几乎垂直。可加大双腿不对称（一腿抬起/外摆）、让裙摆更"堆"、或把髋部再压低 5–10px。
3. **跨边依赖 wipe**：18px 羽化的自上而下揭示，暂停看像帘子；播放时基本读作裙摆倒下来。
4. **手臂不发力**：撑起感靠躯干、裙摆、手；如果需要"手臂用力"，必须回到 IK + 补件。
5. **不是无缝循环**：结尾定格后跳回发顶；常驻循环需要补"下去/离开"段。
6. **死代码**：`climb_rig.py` 里还留着 IK、单膝勾（`HOOK`）、`GRIP`、`hands_clip`、`render_frame` 旧逻辑、腋下补片等废弃分支；`climb_timeline.py` 的 `arms_front`/`arms_alpha` 也是死字段。生产前清理。
7. **调试图过多**：工作目录约 90 个 `dbg-*.png`（约 100MB）。交接/提交前只保留 `window-climb-live2d-v4.gif`、`strip-v4.png`、`last-frame-v4.png`、`scene-bg.png`、`climb_rig.py`、`climb_timeline.py`、`live2d-parts/`。

## 8. 下一步（建议顺序）

1. 给用户看 v4；若接受观感 → 清理调试图/死代码，定 v4 为基线。
2. 接入桌宠：新增动作 `window_climb_sit`，触发点为窗口左上/右上角，时长约 2.64s（到落座定格），落座后交给现有 attach/corner 逻辑保持。
3. 若不接受"手臂不发力"：补手臂合成件（从 `arm_l/r` 切 upper+fore，按肩点/沿点两段摆放，腋下用肤色垫片），再启用 IK。
4. 最终形态建议仍是原生 Live2D/Spine 骨骼；当前这套是验证动作可行性的离线合成，不是运行时方案。
5. 注意：`WALL` 裁剪/wipe 只属于本动作，不要带进常态渲染。
