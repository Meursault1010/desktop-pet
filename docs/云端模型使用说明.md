# Yuki 云端模型使用说明

## 支持范围

Yuki 使用 **OpenAI Chat Completions 兼容接口**，通过 HTTPS 调用云端模型。支持流式回复、模型列表发现、API Key、对话取消和本次运行内的上下文。

云端聊天会把你发送的对话内容、人设与长期记忆发送给所选服务。云端附件默认关闭授权；开启后，每次发送含附件的消息都会显示接收端点、文件清单和实际提取的文字，用户检查后还需确认。图片可按每张图片的模式发送处理后的图片、OCR 文字或两者；图片在本机按需缩小至最长边 1536 像素。文档解析与 OCR 在本机完成，图片和提取文字只会在确认后发送给当前云端服务。

## 配置步骤

1. 用 Electron 版启动 Yuki，打开工作台。
2. 进入 **AI 助手 → 模型配置**。
3. 选择 **云端 API**。
4. 选择常用地址，或填写自定义 HTTPS 地址：

   - OpenAI：`https://api.openai.com/v1`
   - DeepSeek：`https://api.deepseek.com/v1`
   - 其他服务：填写其 OpenAI Chat Completions 兼容的 API 根地址，通常以 `/v1` 结尾。

5. 点击 **测试连接并读取模型**。服务不提供模型列表时，测试会说明密钥尚未验证，可按服务商文档手动输入模型 ID。
6. 填写模型名称，例如服务控制台显示的模型 ID；填写 API 密钥并点击 **保存配置**。
7. 回到 **AI 助手 → 与雪对话**，从“当前模型”中选择模型后即可发送消息。

在对话输入栏旁边可以选择 **思考程度**：`自动`、`低`、`中`、`高`。默认是自动，不向服务发送额外参数；选择其他档位时，云端请求会发送标准 `reasoning_effort` 字段。只有支持该字段的推理模型会实际使用它，普通模型或不支持该字段的服务应保持“自动”。

## 模型名称

模型名称必须使用服务实际接受的 ID，不能只填写展示名称。若服务支持 `GET /models`，Yuki 会自动列出模型；若服务不提供模型列表，填写模型名称后仍可直接使用，界面会保留该模型。

## 常见问题

### 显示“远程模型请使用 HTTPS”

远程 HTTP 地址会被拒绝。请使用服务提供的 HTTPS 地址；HTTP 仅允许 `localhost`、`127.0.0.1` 和 `[::1]` 的本机服务。

### 显示 401 或 403

API 密钥无效、权限不足或模型未授权。根据连接测试提示检查密钥与账号权限。更换密钥后保存会替换旧密钥；点击“移除已保存的主连接密钥”并确认后，可单独清除本机保存的主连接密钥。清除主密钥不影响档案中独立保存的密钥。

### 显示 404 或模型不存在

确认地址是 API 根地址而不是网页地址，并确认模型 ID 完全匹配服务文档。常见格式是 `https://服务域名/v1`，不要把 `/chat/completions` 直接填进服务地址。

### 能连接但发送失败

当前协议要求服务支持 `POST /chat/completions` 和 SSE 流式响应。只支持 Responses API、非流式专用接口或自定义请求格式的服务不能直接使用。

### 连接测试显示服务不提供模型列表

部分兼容服务没有实现 `GET /models`。连接测试会标记“服务未提供模型列表，密钥尚未验证”；按服务商文档填写精确的模型 ID 后仍可保存并尝试使用。

### API 密钥是否会明文保存

Electron 会优先使用系统安全存储加密密钥。若系统加密不可用，设置页会提示密钥只能保留到本次运行；不要在共享电脑上继续使用该配置。

## 安全与隐私

- 不要把 API 密钥写入代码、截图、聊天或提交记录。
- 云端服务会收到发送的对话内容，以及已填写的人设与长期记忆。
- 云端附件默认不授权。开启授权后，发送前会显示文件、接收服务和可展开的 OCR/文档提取文字；用户确认后主进程再次校验授权和本次确认，再发送附件。
- “仅发送文字”会从本次请求中排除附件；附件仍留在输入区以便稍后处理。取消确认时，草稿与附件保留。
- 配置档案可以不含密钥，也可选择加密保存独立密钥。删除档案会一并移除该档案的密钥，但不会影响已加载的主连接。
