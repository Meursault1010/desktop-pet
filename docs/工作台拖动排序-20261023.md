# 工作台拖动排序

## 2026-10-28 当前状态（用户最新要求）

- 只开放两处排序：**五个主栏目**、**各栏目的子栏目**（角色、AI 助手、工具、设置的子标签）。总览区块、设置条目、自定义页面**不**参与排序，也不恢复旧的区块拖柄。
- 操作：拖动整个导航项／子栏目标签；或聚焦后按 `Alt + ↑↓`（横向标签也可用 `Alt + ←→`）。拖动时目标位置显示 2px 冰蓝细线，松手后按 320ms FLIP 衔接（舒缓节奏 1.6×，减少动态时直接跳位）。
- 顺序按稳定标识保存在本机 `localStorage`：主栏目 `yuki-sort:main-navigation`（`overview/character/assistant/tools/settings`），子栏目 `yuki-sort:tabs-<栏目 id>`（存中文标签名）。重新打开工作台恢复；已移除的标识自动过滤，新增项追加到末尾。
- 排序只改变呈现顺序：当前页面、当前子页内容、`aria-selected` 与页面路由语义都跟随标识本身，不随位置变化；点击被移动过的标签仍打开同一内容。
- 实现：`console-v2/frontend/src/components/SortableGroup.tsx`（`sortable` 参数，仅主导航与子栏目传入）、`WorkbenchApp.tsx` 两处调用、`workbench-v3.css` 末尾的拖动状态样式。无新增第三方依赖。

## 历史（2026-10-23 版本，已撤回）

以下为当时的全量实现，2026-10-28 用户要求删除自定义布局与区块编辑时撤回；除上面恢复的两处外不要再依据本段恢复。

- 键盘：聚焦导航项、子栏目标签或拖动柄，按 Alt + 上下／左右方向键调整。
- 总览继续沿用「自定义布局」中的区块排序与尺寸调整，不恢复自定义页面功能。
- 已接入范围：主导航；角色、AI 助手、工具、设置的全部子栏目；通用设置的分组及分组内条目；主题与动态条目；快捷键条目；人设与长期记忆两个编辑区；角色外观参数、行为参数与行为面板；时间管理的专注和休息面板。
