# 工作台拖动排序

## 使用

- 五个主栏目：按住导航项拖到目标栏目上，松开完成换位。
- 各栏目子页：按住标签拖动，松开调整顺序；当前打开的内容保持不变。
- 设置条目及可排序内容块：使用右上角六点拖动柄，避免影响开关、按钮、文本编辑。
- 键盘：聚焦导航项、子栏目标签或拖动柄，按 Alt + 上下／左右方向键调整。
- 总览继续沿用「自定义布局」中的区块排序与尺寸调整，不恢复自定义页面功能。

## 已接入范围

主导航；角色、AI 助手、工具、设置的全部子栏目；通用设置的分组及分组内条目；主题与动态条目；快捷键条目；人设与长期记忆两个编辑区；角色外观参数、行为参数与行为面板；时间管理的专注和休息面板。

## 行为

拖动目标使用细轮廓提示；放下后以 260ms FLIP 位移动画衔接位置变化，支持系统和应用的减少动态设置。排序范围彼此独立，不把设置移进别的表单或栏目。顺序按稳定标识保存在本机 localStorage，重新打开工作台恢复；旧记录里已移除的条目自动过滤，新增条目追加到末尾。拖动不修改宠物偏好、聊天内容或字段值。

当前使用桌面浏览器原生拖放与程序位移动画，无新增第三方依赖。不包含跨设备同步。
