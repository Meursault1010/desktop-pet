# 白发蓝裙角色待机动画

> 已升级为持续呼吸和发丝动画，请以 `LIVING_IDLE.md` 为准；以下是初版素材记录。

素材来源：`图片/待机动作/眨眼/` 的12张原图。原图不作修改；透明导出文件位于 `assets/ice-blue-idle/`。

## 运行方式

退出旧版后，双击 `start.bat`。保留项目里的 `assets` 目录，Python 渲染器会缓存透明 PNG；日常运行不依赖 Pillow/OpenCV。

## 动作规则

- 眨眼结束后随机等待2.8–6.8秒，闭眼85–140毫秒。
- 20%概率追加一次短促双眨眼，间隔120–220毫秒。
- 发丝轻摆每8–16秒随机触发，与眨眼串行播放，避免动作冲突。
- 轻微呼吸以脚底为锚点；“暂停走动”和“安静模式”只停止自主移动，眨眼、发丝轻摆和呼吸仍会继续。
- 隐藏再显示、电脑休眠恢复时重新计时，不补播积压的动作。
- 原第05帧头发形变较大，第07–09帧带张嘴动作，均保留导出，但当前安静待机只使用更稳定的帧。
- 移动、拖动、点击跳跃、大小、不透明度等原有行为保持不变。当前没有新增走路素材，移动时仍使用待机外观。

## 维护

`idle_animation.py`：可独立测试的动作调度；`pet.py`：Qt PNG缓存与绘制。

离线重新处理素材需 Pillow/numpy/OpenCV：

```powershell
python prepare_idle_assets.py "图片/待机动作/眨眼"
```

`pet-sprite-work/final-qa/` 保存浅深背景接触表和示例 GIF。GIF仅用于检查，实际程序不固定循环GIF。
