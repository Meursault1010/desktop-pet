# 小橘桌面宠物

## 新版控制台（React + Tauri）

双击 `start.bat` 打开新版桌面小屋：包含总览、外观、行为、互动、设置五个页面，以及浅色/深色主题。界面通过本地 JSON 管道控制现有 Python 宠物，设置与位置沿用原来的配置。

已编译的控制台在 `app/xiaoju-console.exe`。普通使用无需前端开发服务器；保留项目 Python 文件和 `.venv`。当前版本尚非包含 Python 的独立安装包。重复启动新版会唤起已有控制台，不会再创建一只宠物。

详细的前端结构、开发方法和通信说明见 [FRONTEND.md](FRONTEND.md)。`start_legacy.bat` 或直接运行 `main.py` 可使用原版 Qt 控制台；下面的原版说明仍适用。

Windows 桌面宠物与控制台，Python 3.10+、PySide6。同一程序包含透明宠物窗口、普通设置窗口和系统托盘。

## 启动

首次使用双击 `install.bat` 安装依赖，随后双击 `start.bat`。已有项目虚拟环境无需重新安装。

```powershell
.\.venv\Scripts\python.exe main.py
```

启动时同时显示宠物和控制台；控制台可以调整大小，内容较多时可以滚动。

## 已实现功能

- 宠物显示/隐藏、暂停/继续自主走动、回到当前屏幕底部、手动跳跃。
- 宠物大小（50%～200%）、不透明度（30%～100%）、始终置顶。
- 移动速度（10～150 像素/秒），少动/默认/活跃三档活动频率。
- 自主随机移动、点击问候气泡和安静模式。
- 安静模式临时停止移动和气泡，关闭后恢复原偏好；眨眼、拖动与手动跳跃仍可用。
- 设置修改立即生效并自动保存；记住暂停状态和宠物位置。每次启动显示宠物，避免上次隐藏后无法找到。
- 关闭控制台隐藏到托盘；点击托盘图标重新打开。托盘菜单和宠物右键菜单提供常用操作。
- 无系统托盘时，关闭控制台会最小化窗口，保留重新打开和退出的入口。
- 恢复默认设置需要确认；不删除素材文件。
- 屏幕尺寸或可用工作区变化时校正宠物位置。恢复到不存在的显示器时移回最近的可用屏幕。
- 隐藏宠物时停止动画定时器；明确选择“退出小橘”才关闭整个程序。

暂停只停止自主移动。随机移动关闭或安静模式开启时，暂停按钮暂不可用。动作测试时请先显示宠物。跳跃沿用现有动画；本版本没有新增挥手素材。

## 配置

偏好通过 Qt 的本地 INI 配置保存，通常位于 `%LOCALAPPDATA%\XiaoJu\DesktopPet\settings.ini`，不写入程序安装目录。位置在移动期间每两秒保存一次，拖动结束、设置改变和正常退出时也会保存。

测试或独立配置可使用：

```powershell
.\.venv\Scripts\python.exe main.py --settings-file .\test-settings.ini
```

## 文件结构

- `main.py`：入口、共用控制层、托盘、程序生命周期。
- `console.py`：控制台窗口与设置控件。
- `pet.py`：宠物窗口、动画、绘制与鼠标交互。
- `settings_model.py`：默认设置、输入校验与本地存储。
- `test_console.py`：独立临时配置的离屏功能验收。
- `控制台第一版需求文档.md`：第一版需求和验收依据。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest test_console -v
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe main.py --smoke-test --settings-file .\smoke-settings.ini
```

验收测试不操作真实托盘，不使用个人配置。`qa` 下生成控制台与宠物截图。真实 Windows 的托盘交互、多显示器和不同缩放比例仍需桌面体验验收。
