# 依靠桌面图标睡眠（自然背靠版）

## 自然睡姿与遮挡

控制台「依靠睡眠 → 自然睡姿」可选择自动、左侧背靠、右侧背靠、背对屏幕、正面背靠。
默认自动选择侧面或背面姿势，正面可以手动选择。所有姿势使用同一套分层规则。
接触点按肩背定位，允许脚底低于图标，不强行底部对齐。图标作为有高度的虚拟靠背。
仅依靠的目标图标与蓝色裙摆重叠处允许遮挡裙摆。白色头发（包括长发末端）始终保持前景。
其他桌面图标不参与裁切，所有文字也不参与裁切，宠物可以显示在它们之上。
裙摆遮罩根据现有白发蓝裙素材的腰线与颜色生成，保守保留浅色花边，避免误切头发；
更换角色配色或服装后需重做裙摆遮罩。遮罩逐帧随呼吸同步，不用水平切线直接截断整个人物。
背面与侧面素材重新按原参考图和三视图生成，运行素材位于 assets/icon-sleep-v2。
生成脚本 generate_natural_sleep.py、背景修正 fix_sleep_background.py 保存完整提示词；
原图与背景修正版位于 action-work/icon-sleep-v2，QA组合图位于 qa/icon-sleep-v2。

## 入口与使用

运行 start.bat，左侧打开「依靠睡眠」。刷新图标，选择目标，再点击「靠着睡觉」。
宠物平滑靠近后，以无道具的坐姿持续呼吸。可以选择自动、左后方、正后方、右后方。
系统文件夹、普通文件夹和其他桌面文件图标都可选择；周围图标密集不作为拒绝依靠的条件。
按每个睡姿的真实透明轮廓和整个呼吸周期定位，不把透明窗口空白当作身体。
靠近屏幕边缘时，即使手动指定方向，也优先改用能完整显示身体的方向；三方向均无法原位放下时，
最小幅度向屏幕内移动。此时接触位置可能略有偏离，可用偏移微调。只有身体本身大于可用屏幕时才提示缩小。

## 可控参数

- 水平/垂直偏移：-100～100 个 Qt 逻辑像素，默认 0，用于不同图标的接触位置微调。
- 呼吸强度：0～100%，默认 55%。0 停止呼吸变形，不影响其他待机设置。
- 睡眠时长：0～120 分钟，默认 0（持续睡眠）。到时结束依靠。
- 拖到图标附近自动依靠：默认关闭。开启后定期更新目标，拖动松手才检查附近图标。
- 自动依靠距离：30～240 个逻辑像素，默认 100。按角色下背部附近到图标的距离计算。

以上参数保存到原设置文件的 icon_sleep 分组，不覆盖已有外观和行为偏好。不自动恢复上次睡眠目标。

## 退出与保护

控制台「醒来」、宠物点击/拖动、跳跃、手动播放其他动作、回到底部、隐藏宠物均结束依靠。
更改宠物大小、置顶方式或显示器布局也会结束依靠，避免坐标失效。安静模式不会停止睡眠呼吸。
图标移动、删除、改名或桌面不可用时自动醒来。不会修改、打开、移动或删除桌面文件。
不再因为普通窗口与宠物区域有任何交叠就停止绘制整只宠物。依靠沿用宠物本身的置顶设置；
尚未实现普通应用窗口对身体的局部遮挡。图标轮廓加载期间也会继续显示角色。
只有目标图标与裙摆重叠的裁切区域允许直接操作底下的图标；头发、文字所在处仍可点击宠物。

## 实现与限制

desktop_icons.py 使用 Windows Shell 的 IFolderView2、IShellFolder 和 IAccessible 只读获取图标，
获取实际项目边界、图标尺寸以及带 alpha 的 Shell 图标位图。原生坐标按各显示器比例转为 Qt 坐标。
icon_sleep.py 负责后台扫描、轮廓安全边界、接触点定位、平滑靠近、持续呼吸和图标轮廓遮挡。
后台扫描不在绘图帧回调中执行；图标本身始终是原来的 Explorer 图标，不是复制出来的假文件。

第一版是透明窗口的二维视觉遮挡，不把窗口注入 Explorer。接近时使用现有角色平滑平移，尚无专门的
转身坐下、起身或绕障碍路径动画。睡姿由参考图、三视图通过 shengtu-skill GPT 编辑生成，呼吸由程序连续变形。
原始生成图与提示词存放于 action-work/icon-sleep；运行素材在 assets/icon-sleep。
当前电脑 150% 缩放完成坐标与真实桌面扫描检查；混合 DPI、多显示器仍建议在实际显示器上验收并按需微调。
