# Yuki · 桌面上的一天

30 秒 Windows 桌面伙伴介绍片。1920×1080，30 fps，中文字幕。卡林巴、电钢琴和轻木击组成原创配乐，独立合成弹响与铃音。

以贴纸绘本的剪纸边缘、Windows 桌面的空间关系和 Yuki 原有动画组成一个桌面小剧场。左侧主文案从称呼到功能，右侧把同一块桌面交给角色玩耍。主色取冰蓝、奶白与银灰，聊天和专注段分别加入淡粉与薄荷。字体使用粗体中文和圆润的 DM Sans。

考虑过按功能逐一切镜、跟随角色在桌面移动和从工作台界面出发三个结构。采用跟随角色的结构，窗格和桌面图标作为空间锚点，聊天、计时和音乐从相应动作出现。界面是功能示意，角色为项目内真实帧素材。

| 时间 | 画面 | 声音 |
| --- | --- | --- |
| 0–5 秒 | 雪花贴纸落下，Yuki 出现在桌面窗格里挥手 | 卡林巴动机，挥手轻响 |
| 5–10 秒 | 文件夹滑入桌面，Yuki 从边上探头 | 木击与弹响 |
| 10–15 秒 | 点击之后展开聊天气泡，一来一回 | 两次音高不同的提示 |
| 15–20 秒 | 对话收起，专注计时从 25:00 启动，Yuki 打开书 | 配器变轻，开始按钮短响 |
| 20–25 秒 | 桌面音符开始跳动，Yuki 使用实际舞蹈帧跟随音乐 | 卡林巴动机再现，加入木击 |
| 25–30 秒 | 窗格收成贴纸，角色回到画面中心附近挥手 | 和弦落定 |
